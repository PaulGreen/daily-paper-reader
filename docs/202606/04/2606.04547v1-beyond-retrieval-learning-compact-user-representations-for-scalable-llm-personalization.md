## 摘要
个性化大规模语言模型需要根据个体用户调整模型行为，同时保持鲁棒性和部署效率。现有方法通常在输入层面对LLM进行个性化，通过检索用户历史或构建画像提示，或在参数层面通过维护用户特定的参数高效模块。前者使得个性化对检索质量和提示设计敏感，而后者则随着用户数量的增加产生存储和维护成本。为了解决这些限制，我们提出了TAP-PER（用于个性化的时间注意力前缀），一种基于前缀的框架，将用户偏好编码为可学习的表征，消除了显式提示构建，并用轻量级的用户状态前缀嵌入取代了沉重的逐用户适配器。受个性化推荐系统启发，TAP-PER将用户建模分解为用户状态和查询条件组件，并融入时间信号以捕捉用户兴趣的动态演变特性。在六个LaMP任务上的实验表明，TAP-PER在分类、评分和生成场景下始终优于基于提示和基于模型的基线方法。此外，在1000用户规模下，TAP-PER使用的逐用户参数比OPPU少130倍，总参数占用量约为PER-PCS的一半，表明无需显式提示构建或沉重的逐用户适配器即可实现可扩展的LLM个性化。

## Abstract
Personalizing large language models requires adapting model behavior to individual users while preserving robustness and deployment-scale efficiency. Existing approaches typically personalize LLMs either at the input level, by retrieving user histories or constructing profile prompts, or at the parameter level, by maintaining user-specific parameter-efficient modules. The former makes personalization sensitive to retrieval quality and prompt design, whereas the latter incurs storage and maintenance costs that grow with the user population. To address these limitations, we propose TAP-PER (Temporal Attentive Prefix for PERsonalization), a prefix-based framework that encodes user preferences as learnable representations, eliminating explicit prompt construction and replacing heavy per-user adapters with lightweight user-state prefix embeddings. Inspired by personalized recommendation systems, TAP-PER decomposes user modeling into user-state and query-conditioned components, and incorporates temporal signals to capture the evolving nature of user interests. Experiments on six LaMP tasks show that TAP-PER consistently outperforms prompt-based and model-based baselines across classification, rating, and generation settings. Moreover, TAP-PER uses 130x fewer per-user parameters than OPPU and roughly half the total parameter footprint of PER-PCS at the 1,000-user scale, demonstrating that scalable LLM personalization can be achieved without explicit prompt construction or heavy per-user adapters.

## 1. 研究背景与核心问题
- **核心问题**：大语言模型（LLM）的个性化需要使输出适配个体用户的偏好（如风格、长期兴趣），但现有方法要么依赖检索或画像提示（对检索质量与提示设计敏感），要么为每个用户维护专属的适配器模块（存储与维护成本随用户量线性增长）。同时，多数方法忽略用户兴趣的时间动态性。
- **动机**：寻求一种**无需显式提示构建、不依赖沉重逐用户适配器、支持时间建模且可大规模扩展**的个性化方案。受推荐系统中可学习用户嵌入与序列建模启发，论文提出将用户偏好编码为紧凑的、可端到端优化的表示。

## 2. 方法论：TAP‑PER 框架
### 2.1 总体思想
TAP‑PER 采用**两阶段训练**，将个性化分解为任务适应与用户表示学习：
- **阶段一：任务级适应**  
  用所有用户聚合数据对主干 LLM 进行 LoRA 微调，使其具备目标任务能力。训练后 LoRA 参数**合并入主干**，冻结为 `θtask`。
- **阶段二：个性化前缀学习**  
  在冻结的 `θtask` 上，通过学习两种**前缀嵌入**（连续向量）和一个共享的**桥接 LoRA** 来实现用户个性化，不修改主干。

### 2.2 关键技术细节
- **用户状态前缀 (Pu)**  
  为每个用户 `u` 维护一个可学习嵌入表 `E ∈ ℝ^{|U|×(L×d)}`，将其重塑为前缀矩阵 `Pu ∈ ℝ^{L×d}`，捕获用户的长期、跨查询的稳定偏好。
- **查询感知的记录前缀 (Pq)**  
  对于查询 `q` 和用户的完整交互历史 `H_u`，通过以下步骤动态生成与查询相关的历史证据前缀：
  1. **记录表示**：用冻结主干的嵌入层对历史记录 `h_j` 取平均池化得到 `z_hj`，对查询同理得 `z_q`（可预计算并缓存）。
  2. **注意力计算**：采用 **DIN 风格注意力**，不使用外部检索器，直接在整个历史上计算：
     ```
     s_j = MLP( [z_q; z_hj; (z_q - z_hj); (z_q ⊙ z_hj)] )
     ```
  3. **时间偏差**：引入可学习的**时间间隔衰减系数 `λ_t`** 和**顺序间隔衰减系数 `λ_o`**：
     ```
     s̃_j = s_j - λ_t·log(1+Δ_tj) - λ_o·log(1+Δ_πj)
     ```
     其中 `Δ_tj` 为查询与记录的时间差，`Δ_πj` 为顺序索引差。
  4. **聚合与投影**：`α_j = softmax(s̃)`，加权和 `Σ α_j·z_hj` 经 MLP 映射到前缀空间得到 `Pq ∈ ℝ^{L×d}`。
- **前缀组合**：`Pu,q = Pu + Pq`（元素级相加）。
- **桥接 LoRA**：在每一 Transformer 层的 Q、K、V、O 投影矩阵上施加**共享的 LoRA 适配器** `Δθbridge`，与前缀参数联合训练，使前缀信号更深层地介入主干。
- **训练目标**：交叉熵损失 `CE(LLM(Pu,q, q; θtask + Δθbridge), r)` 联合优化前缀参数（用户嵌入、注意力 MLP、衰减系数、投影 MLP）与桥接 LoRA。

### 2.3 设计优势
- 取代了 RAG 的文本检索和 PAG 的自然语言画像，所有历史证据通过可学习注意力加权，**端到端优化**。
- 时间偏差使模型能区分近期/早期交互，**感知兴趣演化**。
- **极低的逐用户开销**：仅需存储 `L×d`（约 32K 参数）的用户状态前缀，其余部分全用户共享。

## 6. 主要结论与发现
- **性能全面占优**：在全部 6 个 LaMP 任务的所有指标上，TAP‑PER 均优于最优的基于提示和基于模型的基线；尤其在高要求个性化任务（如 LaMP‑2M 准确率提升 7.2%，LaMP‑5 ROUGE‑1 提升 2.8%）增益显著。
- **消除检索与提示脆弱性**：通过可学习前缀替代文本，避免了不同任务间需调优检索 k 值和画像构建的不稳定性。
- **极高参数效率**：1000 用户下，逐用户存储仅 32K 参数，约为 OPPU 的 1/130，总参数量约为 PER‑PCS 的一半；桥接 LoRA 与注意力机制为全用户共享。
- **时间建模有效**：同时使用时间和顺序衰减可提升性能，尤其对时间敏感任务；注意力可视化证实模型能正确关注近期相关历史。
- **无需预检索**：直接在全历史上进行时序注意力优于 BM25 预过滤，表明端到端学习可自行筛选相关记录。
- **支持轻量在线适应**：仅更新用户状态前缀 Pu（~32K 参数）即可有效吸收流式反馈，在标题生成等任务上接近于完全重训的效果。

## 7. 方法亮点
- **表示中心化**：将个性化建模从提示工程转为可学习嵌入，与推荐系统思想一脉相承，简洁而有效。
- **时序感知的前缀设计**：独创地将 DIN 式注意力与时序/顺序偏差结合，使连续前缀能自适应捕获近期证据。
- **模块化解耦**：用户长期偏好（Pu）与查询相关历史（Pq）分别建模，且与任务适应及桥接 LoRA 协同，各组件功能清晰。
- **超低逐用户成本**：每用户仅需存取一个小嵌入，非常适合大规模部署。
- **保持通用能力**：阶段一的任务适应被合并，阶段二只添加新参数，避免遗忘；同时支持在线连续适应。
- **实验验证全面**：涵盖分类、回归、生成，多种消融、效率分析和适应性实验，结论可靠。

## 8. 不足与局限
- **极端历史长度的鲁棒性**：当用户历史极长或噪声很多时，全历史的注意力质量可能下降，论文未探索结合稠密检索器或学得检索器的方案。
- **骨干规模验证有限**：仅在 8B 和 4B 两类模型上验证，未在更大规模模型（如 70B+）上证明增益持续性。
- **隐私与伦理**：虽然采用连续嵌入降低原文泄露风险，但嵌入仍编码了行为模式，需做好访问控制和审计；时序衰减可能放大近因偏差，有强化过滤气泡的风险，作者也建议定期审计并让用户控制个性化强度。
- **任务覆盖**：LaMP‑6 和 LaMP‑7 因数据问题未包含，但仍覆盖了主要的分类与生成任务。
