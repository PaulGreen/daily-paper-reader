## 摘要
提示知识截止指令大型语言模型（LLM）假设在指定截止日期之后的信息不可用。然而，先前的工作主要依赖于直接答案生成，当截止后的知识并非被显式查询，而仅与问题存在因果关联时，该方法便显得力不从心。为克服这一局限，我们提出了两种基于回忆的提示策略：自回忆（SR），即要求模型重述其截止约束；问题回忆（QR），要求模型回忆在截止条件下有效的问题相关信息。在三个现有基准测试中，我们的方法均优于直接答案提示和传统的逐步推理基线，尤其在反事实问题上取得了显著改进。为探究不同截止设置下的鲁棒性，我们进一步构建了多截止历史事件基准（MHEB），该基准在多个截止年份下对同一问题进行评估。结果显示，知识截止性能随截止距离而变化，而将SR与QR相结合则始终能获得最佳性能。

## Abstract
Prompted knowledge cutoff instructs a large language model (LLM) to act as if information beyond a specified cutoff date were unavailable. However, prior work mainly relies on direct-answer generation, which struggles when post-cutoff knowledge is not explicitly queried but is only causally related to the question. To address this limitation, we propose two recall-based prompting strategies: Self-Recall (SR), which asks the model to restate its cutoff constraint, and Question-Recall (QR), which requires the model to recall question-relevant information valid under the cutoff. Across three existing benchmarks, our methods outperform both direct-answer prompting and conventional step-by-step reasoning baselines, with particularly strong improvements on counterfactual questions. To investigate robustness across different cutoff settings, we further construct the Multi-cutoff Historical Event Benchmark (MHEB), which evaluates the same question under multiple cutoff years. Results show that knowledge cutoff performance varies with cutoff distance, while combining SR and QR consistently yields the best performance.

## 1. 论文的核心问题与整体含义

- **背景与动机**：大语言模型（LLM）在预训练时使用了跨越多个年份的大规模语料，导致其知识可能受到“数据污染”——当评估时间预测任务时，模型可能只是从记忆中回忆出预训练时见过的信息，而非进行真正的时间推理。为了确保时间推理基准测试的可信度、防止知识泄露，要求模型仅基于某个截止日期之前的知识进行回答就显得至关重要。
- **现有方法的不足**：已有的“提示知识截止”方法依赖直接答案生成，在**反事实问题**（即截止后的知识并非直接出现在问题中，而只是因果性地影响答案）上效果急剧下降。此外，现有基准仅给每个问题设定一个固定的截止年份，无法衡量截止年份距离事件发生时间不同时的性能变化。
- **本文目标**：提出并验证两种基于“回忆”的提示策略，以改进LLM在知识截止指令下的表现，尤其是增强在处理因果性相关问题和不同截止距离时的鲁棒性。

## 2. 方法论

### 2.1 自回忆（Self-Recall, SR）
- **核心思想**：在模型给出最终答案前，要求其**显式重述自己的截止约束**，输出一句简短的“自定位声明”（如“我的知识仅限于公元XXXX年12月31日之前的公开信息”）。
- **作用机制**：将来自外部的指令转化为模型自身的内部状态声明，使得时间边界在整个生成过程中更可能被遵守。

### 2.2 问题回忆（Question-Recall, QR）
- **核心思想**：要求模型在回答前，**回忆与问题相关且在截止条件下有效的事件、事实或状况**，并附带对应年份，输出为一个简短的概述句。
- **作用机制**：将知识检索显式锚定在指定截止日期上，抑制模型调用截止后信息的倾向。

### 2.3 组合策略与设计原则
- 除单独使用外，本文还测试了两种组合顺序：**SR → QR**（先自回忆后问题回忆）和 **QR → SR**（先问题回忆后自回忆）。
- 两种提示的中间输出均被限制为**单个简短句子**，不要求结构化推理或逐步解释，旨在**控制知识选择而非增强推理能力**，避免引入可能诱发后截止知识泄露的复杂推理过程。

## 3. 实验设计

### 3.1 基准数据集
- **已有基准（Gao et al., 2025）**：
  - **Factual**：二元选择题，询问直接的事实变化（如“印度现在能否访问TikTok？”），要求模型在截止条件下选出正确选项。
  - **Semantic**：自由形式定义任务，测试词义随时间的变化（如“flash mob”在2003年前尚无定义），通过语义相似度衡量是否成功回到截止前的含义。
  - **Counterfactual**：四项选择题，需要基于截止前知识推断假设性结果（如“在不知道延迟决定的情况下，2015年非洲国家杯主办国是谁？”），分别用Hard（必须选对正确答案）和Soft（只要不选无截止时的答案）指标评估。
- **新构建基准：多截止历史事件基准（MHEB）**
  - 从Wikidata收集**900个历史事件**（战争、战役、事件类），每世纪100个（13–21世纪），事件发生年份均被模型在无截止条件下正确识别。
  - 每个事件被格式化为“{事件名称}曾经发生过吗？”的二元问题，并在**事件年及其之前9年（共10个偏移）**设置截止年份，正确答案随截止位置变化（截止在事件年或之前时答案为“否”）。

### 3.2 对照方法
- **P1（基础提示）**：来自Gao et al.的直接截止指令，要求模型假设记忆截至前一年12月31日，并直接给出答案。
- **逐步推理基线**：在P1基础上分别加入**零样本思维链（ZS-CoT，附加“让我们逐步思考”）**和**零样本计划与解决（ZS-PS，先规划再求解）**两种经典提示策略。

### 3.3 评估模型
- GPT-4o、gpt-oss-120b、Llama-3.3-70B-Instruct，推理时温度均设为0，以确定性输出确保复现性。

## 5. 实验数量与充分性

- **实验矩阵庞大**：在三个已有基准（Factual 675、Semantic 303、Counterfactual 689 个经过过滤的实例）上，对3个模型、7种提示配置（P1、ZS-CoT、ZS-PS、SR、QR、SR→QR、QR→SR）进行全面评估，共计 **3×7×3 组主实验**；其中 Counterfactual 还报告了 Hard 和 Soft 两个维度的指标。
- **多截止鲁棒性检验**：在 MHEB 的 900 个事件、10个截止偏移下，使用 **Llama-3.3-70B-Instruct** 测试所有提示方法，产生 **7×10** 列结果，系统分析了截止距离的影响。
- **实验控制与公平性**：Factual 和 Counterfactual 均预先筛选了所有模型在无截止条件下都能正确回答的实例，从而确保失败源于知识抑制问题而非事实缺失；所有对比在同一提示基底 P1 上增加中间步骤，保证变量控制；温度固定为0，消除随机性干扰。整体实验量充足，设计合理客观。

## 6. 主要结论与发现

1. **回忆提示普遍优于基线**：SR 和 QR 在绝大多数模型与数据集组合上均击败直接回答 P1 和逐步推理基线 ZS-CoT、ZS-PS，尤其在 **Counterfactual** 任务上提升尤为显著（如 Llama3.3 的 Hard 成功率从 P1 的0.390 提升到 SR 的0.532 及 SR→QR 的0.586）。
2. **逐步推理可能有害**：ZS-CoT 和 ZS-PS 经常导致性能下降，尤其在 Counterfactual 任务中，因为中间推理会诱发模型检索到截止后的事实，从而违反截止约束。
3. **SR→QR 组合性能最优**：先声明截止立场（SR）再回忆截止前相关信息（QR）的次序，在几乎所有基准和 MHEB 中均取得最高成功率，说明角色强化能有效引导后续的时间锚定。
4. **截止距离的影响**：在 MHEB 上，P1 和 SR 在截止距事件年更远时成功率更高（“时间越久越容易忘”）；而逐步推理方法在截止恰等于事件年（距离0）时效果最好，推测是其生成了与事件时间相关的线索，但距离加大后该线索不再可靠。
5. SR→QR 在不同截止距离下表现**始终稳健且最优**，展现了强泛化能力。

## 7. 优点

- **方法简洁且无需训练**：仅通过修改提示，即可在纯黑盒 API 模型上实现性能提升，无需额外微调或内部参数访问。
- **揭示认知新机理**：明确指出逐步推理在知识截止任务中的反效果，提示“控制知识检索”与“增强推理能力”需区别对待，为后续提示设计提供了新视角。
- **构建新基准 MHEB**：首次实现同一问题在多个截止年份下的系统性评估，能更精细地衡量时间约束的鲁棒性。
- **实验覆盖全面**：多模型、多数据集、多提示组合、多截止距离，且在 Counterfactual 上区分 Hard/Soft 指标，增强了结论的可信度。

## 8. 不足与局限

- **语言限制**：所有提示和基准均为英文，未扩展到多语言场景，无法评估跨语言泛化能力。
- **模型覆盖**：MHEB 实验仅在一款模型（Llama-3.3-70B-Instruct）上开展，其他模型的跨距离性能未知。
- **遗忘程度有限**：该方法仅通过提示抑制后截止知识，**不能保证真正的“遗忘”**，模型内部参数仍保有完整信息，可能被越狱或误用。
- **继承偏见与幻觉**：所用 LLM 本身可能携带训练数据中的社会偏见或产生幻觉，提示策略可能无法完全消除这类风险。
- **未探索遗忘方法融合**：受算力限制，论文未将提示方法与需要微调的机器遗忘技术（如梯度修改）进行对比或结合，可能遗漏更高安全等级的方案。
- **基准依赖 Wikidata**：MHEB 事件取自 Wikidata，其覆盖面和真实性偏差可能传导到评估结果中。
