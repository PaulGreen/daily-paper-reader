## 摘要
系统提示优化能够在不修改底层模型的情况下改善智能体行为，生成人类可读、模型无关的指令。现有方法构建一个提示智能体来优化任务智能体的系统提示，但提示智能体自身的系统提示仍为手工设计且固定不变。我们提出自进化提示优化（SePO），将提示智能体自身的系统提示与任务智能体的系统提示一同作为优化目标。SePO采用自指设计，单个提示智能体在开放式进化搜索中同时改进任务智能体的系统提示和自身的系统提示，并维护一个候选提示存档作为垫脚石。训练分为两个阶段：预训练在多任务池上演化提示智能体，随后微调将其应用于目标任务。在涵盖数学（AIME'25）、抽象推理（ARC-AGI-1）、研究生水平科学（GPQA）、代码生成（MBPP）和逻辑谜题（数独）的五个基准测试上，SePO始终优于Manual-CoT、TextGrad和MetaSPO，相比Manual-CoT平均准确率提高4.49个百分点。预训练获得的提示优化技能也能泛化到预训练混合任务之外的任务，而非记忆每个任务的提示。

## Abstract
System prompt optimization improves agent behavior without modifying the underlying model, yielding human-readable, model-agnostic instructions. Existing methods build a prompt agent that refines task agents' system prompts, yet leave the prompt agent's own system prompt hand-engineered and fixed. We propose Self-Evolving Prompt Optimization (SePO), which treats the prompt agent's own system prompt as an optimization target alongside task agents' system prompts. SePO adopts a self-referential design. A single prompt agent improves both task agents' system prompts and its own under an open-ended evolutionary search that maintains an archive of candidate prompts as stepping stones. Training proceeds in two stages: pre-training evolves the prompt agent on a multi-task pool, and fine-tuning then applies it to a target task. Across five benchmarks spanning math (AIME'25), abstract reasoning (ARC-AGI-1), graduate-level science (GPQA), code generation (MBPP), and logic puzzles (Sudoku), SePO consistently outperforms Manual-CoT, TextGrad, and MetaSPO, improving the average accuracy by 4.49 points compared to Manual-CoT. The prompt optimization skill from pre-training also generalizes to tasks beyond the pre-training mixture, rather than memorizing per-task prompts.

### 1. 研究动机与核心问题

- **背景**：当前智能体在推理、编程、决策等任务中被广泛部署，系统提示优化可在不修改模型权重的情况下提升智能体表现，且生成人类可读的通用指令。
- **现有方法的局限**：主流的提示优化方法（如 TextGrad、MetaSPO、PromptBreeder）皆引入一个“提示智能体”来阅读评估反馈并迭代改进任务智能体的系统提示，但该提示智能体自身的系统提示始终是**手工编写且固定不变**的。因此，优化性能的上限受限于人工设计，且无法从多次优化任务中积累经验。
- **核心问题**：能否将提示智能体自身的提示也纳入优化循环，使其随任务经验而进化，从而突破人工设计的“天花板”？

### 2. 方法论

**核心思想：自指进化框架（SePO）**

- 将提示智能体看作一种特殊的“任务智能体”，其系统提示本身也是优化变量，与任务智能体的提示一同被优化。
- 采用**开放式进化搜索**：维护一个候选提示档案库，每一代从库中按概率采样父代，由提示智能体生成子代提示，并依据得分决定是否将子代纳入档案，档案中的旧提示可作为后续改进的“垫脚石”。

**两阶段训练流程（图 2）**

1. **预训练（Pre-training）阶段**  
   - 在多个任务组成的任务池上，将提示智能体自身的系统提示从手工初始种子进化为最优 `p̃*`。此阶段激活“自指闭环”：每次生成子代时，提示智能体使用的正是其**当前自身的系统提示**，即它在改进一个“复制体”。
   - 通过该过程，提示智能体获得**通用的提示优化技能**。
2. **微调（Fine-tuning）阶段**  
   - 固定预训练得到的最优提示智能体 `p̃*`，针对单一目标任务，对任务智能体的系统提示执行同样的进化搜索，得到最终的任务提示 `p*`。

**两种配置**

- **SePO-Specialist**：预训练仅使用后续微调所针对的同一任务（单任务）。
- **SePO-Generalist**：预训练采用多任务混合池（基于贪心启发式方法选择任务组合），单一预训练成本可被摊销到多个微调任务上，且利于跨任务泛化。

**关键技术细节**

- **进化搜索**（算法 1）：交替进行父代选择、子代生成、评估与存档准入。
  - 父代选择使用温度自适应、受子代数量惩罚的 softmax，以平衡探索与利用。
  - 子代评分基于其相对于父代在相同评估批上的准确率增量。
  - 存档采用 `keep_better` 策略，只接纳得分不低于父代（在噪声容限内）的子代。
- **提示生成机制**：提示智能体的输入包含任务描述、任务智能体信息、当前系统提示和一批成功/失败案例（约 1:1 平衡），输出为优化后的提示文本，包裹在特定标记中。

### 6. 主要结论与发现

- SePO 在所有五个任务上均取得最高准确率，SePO-Generalist 平均准确率为 76.38%，比 Manual-CoT 高出 4.49 个百分点。
- SePO-Specialist 也全面优于 Manual-CoT，但低于 Generalist，显示多任务预训练的价值。
- TextGrad 和 MetaSPO 在多数任务上表现不如 Manual-CoT，因它们的提示优化器本身固定且无法随搜索过程适应。
- 预训练学到的提示优化技能**并非记忆特定任务提示**，而是可迁移的通用策略，即使对于预训练池中完全不包含的 Sudoku 任务，仍能获得巨大提升。
- 消融表明，自指进化（提示智能体自我改进）与开放式进化存档两者缺一不可。
- 成本上，Generalist 通过摊销预训练成本，使单任务开销低于 Specialist 且可与 TextGrad 相竞争。

### 7. 优点（亮点）

- **新颖的自指闭环设计**：首次将提示智能体自身纳入优化目标，使提示优化能力成为可学习、可积累的技能，突破了手工设计的上限。
- **两阶段“预训练+微调”范式**：模拟成熟机器学习范式，训练和部署分离清晰，成本摊销高效，并为跨任务泛化提供天然支持。
- **开放式进化档案**：利用过去优秀提示作为垫脚石，避免线性搜索易陷入局部最优的缺陷，提升搜索鲁棒性。
- **实验扎实**：涵盖推理、代码、视觉、数独等多样任务，进行多角度验证（泛化、消融、模型替换、成本、定性），结论可信度高。
- **成本可控**：尽管提示智能体被反复调用，但实际产生的 token 消耗因使用精简失败案例和少量输出提示而保持在较低水平。
