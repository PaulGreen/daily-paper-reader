## 摘要
像CLIP这样的视觉语言模型（VLM）实现了强大的零样本识别能力，但在对抗扰动下依然十分脆弱。最近的测试时自适应防御方法通过利用大量增强视图来提高鲁棒性，但这导致了不切实际的减速和明显的鲁棒性与吞吐量之间的权衡。为解决这一挑战，我们提出了稳定性与适宜性引导的测试时提示调优（SS-TPT），通过两个互补的分数评估每个增强视图的质量：（1）稳定性，衡量对弱数据增强的预测不变性；（2）适宜性，衡量视图在特征空间中的密度。这些稳定性与适宜性（SS）分数通过SS引导的一致性损失和SS加权的预测来指导自适应和推理，放大可信视图，同时抑制损坏的视图。大量实验表明，SS-TPT显著优于先前的最先进方法，在不同数据集和不同数量的视图下实现了更优的鲁棒性与吞吐量权衡，从而展示了强大的实用性和通用性。我们的代码可在https://github.com/sunoh-kim/SS-TPT获取。

## Abstract
Vision-language models (VLMs) such as CLIP achieve strong zero-shot recognition but remain highly fragile under adversarial perturbations. Recent test-time adaptation defenses improve robustness by leveraging many augmented views, but this leads to impractical slowdown and a clear robustness-throughput trade-off. To address this challenge, we present Stability and Suitability-guided Test-time Prompt Tuning (SS-TPT), evaluating the quality of each augmented view via two complementary scores: (1) stability, measuring prediction invariance to weak augmentations, and (2) suitability, measuring feature-space density among views. These stability and suitability (SS) scores guide both adaptation and inference through an SS-guided consistency loss and an SS-weighted prediction, amplifying trustworthy views while suppressing corrupted ones. Extensive experiments demonstrate that SS-TPT significantly outperforms prior state-of-the-art methods, achieving superior robustness-throughput trade-offs across diverse datasets and varying numbers of views, thereby demonstrating both strong practicality and generality. Our code is available at https://github.com/sunoh-kim/SS-TPT.

## 1. 研究动机与核心问题
- **背景**：视觉语言模型（VLM，如CLIP）在大规模图文预训练后展现出强大的零样本识别能力，但对对抗扰动极为脆弱。  
- **现有方案**：测试时自适应（Test-Time Adaptation）方法通过生成大量图像增强视图并更新提示（prompt）来提升对抗鲁棒性，但这类方法存在严重的**鲁棒性-吞吐量权衡**：视图越多鲁棒性越强，推理时间却成倍增加（例如R-TPT使用63个视图时，推理速度比原始CLIP慢近4倍）。减少视图数量又会急剧降低鲁棒性，因为少量低质量视图会主导自适应过程。  
- **核心问题**：如何在维持强鲁棒性的同时，大幅降低计算成本，打破视图数量与效率之间的矛盾？

## 2. 方法论
### 2.1 核心思想
提出**稳定性与适宜性引导的测试时提示调优（SS-TPT）**，为每个增强视图计算两个互补的质量分数：
- **稳定性（Stability）**：视图预测对其施加弱随机增强后的不变性程度。  
- **适宜性（Suitability）**：视图在特征空间中与其他视图的密度/接近程度。  

利用这两个分数筛选出可信视图，指导**自适应**（通过SS引导的一致性损失）和**最终推理**（通过SS加权预测），从而抑制损坏视图、放大高质量视图。

### 2.2 关键技术细节
- **稳定性计算**  
  给定视图 \(x_i\) 及其弱增强版本 \(\tilde{x}_i \sim \mathcal{A}'(x_i)\)（包含微小仿射变换、颜色抖动、模糊、噪声等），稳定性定义为预测分布间的 Jensen‑Shannon 散度的倒数：
  \[
  S^{\text{stab}}_i = \left( D_{\text{JS}}(p_{\mathbf{p}}(\cdot|x_i) \| p_{\mathbf{p}}(\cdot|\tilde{x}_i)) + \eta \right)^{-1}
  \]
  分数越高，表示预测对弱扰动越不敏感，视图越可信。

- **适宜性计算**  
  使用归一化特征向量 \(v_i = F(x_i)/\|F(x_i)\|\)，定义余弦诱导距离 \(d_{ij} = 2 - 2v_i^\top v_j\)，适宜性为视角与其他所有视角平均距离的倒数：
  \[
  S^{\text{suit}}_i = \left( \frac{1}{|B|-1} \sum_{j \in B, j \ne i} d_{ij} + \eta \right)^{-1}
  \]
  分数越高表示该视图处于特征空间密集区域，更可能是正常视图。

- **SS分数融合与加权**  
  对稳定性和适宜性分数进行 min‑max 归一化后，线性组合：
  \[
  Z_i = \alpha \bar{S}^{\text{suit}}_i + (1 - \alpha) \bar{S}^{\text{stab}}_i \in [0,1]
  \]
  通过 softmax 得到 SS 权重 \(w_i = \exp(Z_i/\tau_w) / \sum_j \exp(Z_j/\tau_w)\)，其中 \(\tau_w = 0.25\)。

- **SS引导的自适应目标**  
  对每个视图 \(x_i\)，构建**留一法加权参考预测** \(\hat{p}^{(-i)}\)（排除自身，用其他视图的 SS 权重平均），并最小化 KL 散度：
  \[
  \mathcal{L}_{\text{scons}} = \frac{1}{|B|} \sum_{x_i \in B} D_{\text{KL}}\left( p_{\mathbf{p}}(\cdot|x_i) \| \hat{p}^{(-i)} \right)
  \]
  总自适应损失结合**逐点熵最小化**：
  \[
  \mathcal{L}_{\text{adapt}} = \frac{1}{|B|} \sum_{x \in B} H(p_{\mathbf{p}}(\cdot|x)) + \lambda \mathcal{L}_{\text{scons}}
  \]
  其中 \(\lambda = 1\)，\(\alpha = 0.4\)。仅对可学习的文本提示 token 进行一次梯度更新。

- **SS加权预测**  
  自适应完成后，用最终提示 \(p^\star\) 重新计算所有视图的预测，然后通过 SS 权重聚合：
  \[
  \tilde{p}(\cdot | x_0) = \sum_{x_i} w_i \, p_{p^\star}(\cdot|x_i)
  \]
  该加权策略使破损视图对最终预测的贡献被大幅削弱。

## 8. 不足与局限
- **边界风险**：如果多个损坏视图恰好相互高度密集且预测稳定（如都是同一种错误），它们可能被错误地赋予高 SS 分数，从而引导自适应向错误方向偏移。
