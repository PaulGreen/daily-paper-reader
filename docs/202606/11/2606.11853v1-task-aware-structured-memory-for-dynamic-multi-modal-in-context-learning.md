## 摘要
多模态大语言模型依赖上下文学习实现快速任务适应，但其可扩展性受到有限上下文窗口及长多模态序列中键值缓存成本增长的严重制约。现有记忆压缩方法通常依赖僵硬的令牌移除或样本相关的重要性估计，这会引入偏差、破坏语义结构（尤其是视觉表征），并产生无法适应新查询的静态记忆。我们提出TASM（任务感知结构化记忆），这是一种无需训练的框架，通过任务感知、结构保持和动态可访问的记忆构建来解决这些局限。TASM采用任务向量引导压缩，以捕捉跨示范共享相关性的任务级方向替代样本特定信号。为保持底层流形，它通过二分图匹配应用语义感知的令牌合并，在不进行破坏性剪枝的情况下聚合令牌。最后，TASM将记忆构建为包含紧凑核心记忆和潜在库的层次结构，促进查询自适应动态检索。评估结果证实，TASM在重度压缩下仍保持高性能，有效平衡了效率与适应性。

## Abstract
Multi-modal large language models (MLLMs) depend on in-context learning (ICL) for rapid task adaptation, but their scalability is severely limited by finite context windows and the growing cost of key-value (KV) caches in long multi-modal sequences. Existing memory compression approaches typically rely on rigid token removal or sample-dependent importance estimation, which introduces bias, disrupts semantic structure, particularly for visual representations, and yields static memories that cannot adapt to new queries. We introduce TASM (Task-Aware Structured Memory), a training-free framework that addresses these limitations through task-aware, structure-preserving, and dynamically accessible memory construction. TASM employs task-vector guided compression to replace sample-specific signals with a task-level direction that captures shared relevance across demonstrations. To preserve the underlying manifold, it applies semantics-aware token merging via bipartite graph matching, aggregating tokens without destructive pruning. Finally, TASM structures memory into a hierarchy comprising a compact Core Memory and a Latent Bank, facilitating query-adaptive dynamic retrieval. Evaluations confirm TASM maintains high performance under heavy compression, effectively balancing efficiency with adaptability.

## 1. 论文的核心问题与整体含义

多模态大语言模型（MLLMs）在面对长上下文任务时，其键值（KV）缓存的内存开销会随序列长度急剧增长，严重限制了其可扩展性和在消费级硬件上的部署能力。现有的 KV 缓存压缩方法存在三个结构性问题：

- **样本特异性偏差**：基于特定示例答案的注意力分数进行剪枝，会过拟合到这些示例，丢弃对测试查询至关重要但与示例无关的上下文。
- **拓扑结构破坏**：硬剪枝（如 Top‑K 选择）会打断视觉令牌固有的二维空间与语义流形，损害空间定位等任务所需的几何关系。
- **静态记忆刚性**：压缩后的缓存成为固定记忆，无法根据新查询动态恢复被丢弃的信息。

TASM（Task-Aware Structured Memory）的核心目标是构建一种**无需训练**的记忆压缩框架，通过任务感知、结构保持和动态可访问的记忆构造，在重度压缩下仍能维持甚至超越全上下文的多模态上下文学习性能。

## 2. 方法论

TASM 通过三个关键创新来解决上述问题：

### 2.1 任务向量引导的重要性估计
- **任务向量提取**：从少量示例的问题-答案对中，计算问题表征质心 μQ 和答案表征质心 μA，将其归一化差值作为任务向量 τ（式5‑7）。该向量代表了从问题到答案的“推理方向”。
- **正交投影打分**：将缓存中每个令牌的键向量投影到 τ 上，仅取正向投影的 ReLU 值，并结合值向量的范数，得到任务相关分数 sᵢtask（式8）。这过滤了与任务方向正交的噪声。
- **层自适应门控**：浅层保留局部注意力分数 sattn，深层逐渐增加任务分数权重，通过移位 Sigmoid 函数 λ(l) 平滑过渡（式9‑10），避免浅层丢失局部视觉结构。

### 2.2 语义感知的令牌合并
- **图匹配压缩**：将高重要性令牌作为“汇节点”，低重要性令牌作为“源节点”，构造二分图，通过最大化语义兼容性权重 wij 进行一对一匹配（式11‑13）。
- **空间约束**：对视觉令牌施加局部空间窗 Δwin 约束，仅允许邻近的令牌合并，从而保留二维流形结构。
- **流形保持聚合**：将源节点信息加权合并到对应汇节点，形成压缩后的令牌簇质心（式14），实现“软合并”而非“硬删除”。

### 2.3 信息几何动态检索
- **层次化记忆**：维护 GPU 上的紧凑核心记忆（Mcore）和 CPU 卸载的大容量潜在库（Mlatent）。
- **JS 散度触发**：监控当前查询与上一步在核心记忆上的注意力分布之间的 Jensen‑Shannon 散度；当超过阈值 δ 时，触发潜在库的 Top‑k 检索（式15‑17）。
- **按需扩展**：仅在语义上出现“惊奇”时才动态扩展工作记忆，平均保持 O(1) 复杂度。

## 6. 主要结论与发现

- 在同等低内存预算（20%）下，TASM 显著优于所有剪枝基线，甚至**在多任务上超越全上下文 MLoC**，例如 ImageNet‑100 上提升 2.4%，YouCook2 上从 108.8 提升到 109.5。

## 7. 优点

- **完全无需训练**，即插即用，适用于任何预训练多模态大模型。
- **任务感知建模**：用任务向量替代样本相关注意力打分，显著降低偏差和噪声，提升记忆质量。
- **结构保持压缩**：通过带空间约束的图匹配实现软合并，保留视觉令牌的二维流形，避免空间信息丢失。
- **动态自适应检索**：基于信息几何的 JS 散度触发，仅按需检索，平衡效率与完整上下文能力。
- **跨架构通用性强**：在动态高分辨率分块的 InternVL3 上也几乎无损。
- **低计算开销**：在保持高吞吐的同时，显存节省高达 85%。

## 8. 不足与局限

- **任务向量仍需少量示例**：虽然 4 示例即足够，但在极端冷启动（1 示例）下性能下降明显；某些任务可能难以预先获得有代表性的问题‑答案对。
- **层自适应门控依赖经验设置**：参数 α, β, κ 对模型架构和任务可能敏感，论文未给出自动调节方法。
- **动态检索阈值 δ 需人工设定**：阈值与性能之间存在取舍，尚未实现自适应阈值调整。
- **评估主要集中在 7B‑8B 规模模型**：对于更大规模模型（如 30B+）和极长上下文（>100k）的适用性未充分验证。
- **压缩率与任务类型的关系**：在需要极高细节保留的任务（如高精度医学图像）上的性能上限未探索。
- **内存卸载依赖 CPU**：当潜在库极大时，CPU 卸载与 PCIe 带宽可能成为新的瓶颈，而论文未详细讨论极端情况下的延迟。
