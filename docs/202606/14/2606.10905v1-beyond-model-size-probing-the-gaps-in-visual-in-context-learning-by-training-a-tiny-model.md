## 摘要
视觉上下文学习（VICL）旨在推动自适应视觉模型的发展，使其能够基于少量示例在测试时适应新任务。借鉴自然语言处理研究中利用大规模、参数众多模型进行上下文学习的历史，当前 VICL 方法的一条路径是将模型和数据扩展作为关键要素。然而，这些要素是否是视觉模型形成上下文学习的关键尚不明确。为了对这类大型模型进行压力测试，我们用一个极端的反例来挑战它们：我们训练一个仅有一百万个参数和七万张图像的微型视觉上下文模型。我们将这个容量严重受限的微型模型与规模大七千倍的 VICL 模型在不同自适应设置下进行比较，这些设置包括：（1）分布变化较小的图像数据，（2）未见的任务编码，以及（3）一个全新的任务，即 VICL 设想中的场景。鉴于微型和大型模型之间训练资源的巨大差距，我们的实验揭示了当前自适应能力评估中的不足，涉及任务编码方式、预训练中使用的任务以及指标的选择。这些当前 VICL 基准测试中的差距凸显了在评估自适应能力方面需要创新。

## Abstract
Visual in-Context Learning (VICL) aims at making progress towards adaptive vision models, that can -- based on a few examples -- adapt to a new task at test-time. With the history of in-context learning in natural language processing research, where large, parameter-heavy models are in use, one pathway that current VICL methods take is model- and data-scaling as key ingredients. Yet, it is not clear, whether these ingredients are the key for in-context learning to take shape in vision models. To stress-test such large models, we challenge them with an extreme counterexample: we train a tiny visual in-context model with merely $1$ million parameters and a modest amount of $70,000$ images. We compare the results of this severely capacity capped tiny model to $7,000\times$ larger VICL models in different adaptive settings, (1) on image data with small distribution shifts, (2) on unseen task encodings and (3) on a completely new task, i.e., the setting VICL envisions. With the chasm of training resources between the tiny- and large models, our experiments showcase a lack in how adaptive capabilities are measured, with respect to how tasks are encoded, which tasks were used in pre-training and the choice of metrics. These gaps in current VICL benchmarking underscore a need for innovation in evaluation of adaptive capabilities.

### 方法论
1. **模型架构（TinyVICL）**  
   基于医学影像领域的 Neuralizer 架构（一种 1M 参数的 Unet 变体），通过逐对卷积‑平均模块（pairwise conv‑average block）将上下文图像对的信息逐层融合到 query 图像的特征中。输出为三通道 RGB 图像，适用于多种密集预测任务。

2. **多任务预训练**  
   使用 8 个视觉任务数据集：去雨（Rain13k）、深度估计（HRWSI）、语义分割（ADE20K）、图像修复（MVTec AD）、去噪与超分辨率（RAISE）、边缘检测（BIPED/MDBD/COCO 混合）。训练时采用加权采样，使每个任务的采样概率均衡，避免大数据集主导训练。

3. **损失函数设计**  
   - **基础损失**：MSE（逐像素 L2）。  
   - **结构损失**：DSSIM = \(1 - \text{SSIM}(y, y_{\text{pred}})\)，用于保留细节结构。  
   - **新提出的 Palette‑aware Dice 损失（PaD）**：  
     - 从目标图像提取唯一 RGB 颜色集合 \(U\)。  
     - 对每种颜色生成二进制掩码，表示该颜色出现的像素位置。  
     - 对预测图像的每个像素，计算其与各调色板颜色的欧氏相似度，通过 softmax 得到颜色匹配分数。  
     - 使用 Dice 损失对每种颜色的得分进行优化，最终对所有颜色平均。  
     - 该损失强制预测颜色与上下文中的类颜色对齐，显著提升语义分割效果。  
   最终损失组合为：\(L = L_{\text{MSE}} + L_{\text{DSSIM}} + L_{\text{PaD}}\)。

### 主要结论与发现
1. **小分布偏移下，小模型竞争力极强**  
   在训练过的任务上，TinyVICL 在去雨和边缘检测的几乎所有指标上均大幅超越 LVM、DeLVM 等大模型，表明小模型完全能够学会任务并适应轻微的数据分布变化。

2. **任务编码的敏感性远超模型规模的影响**  
   当边缘检测 prompt 从黑边/白底变为白边/黑底时，LVM 的表现剧烈波动（F1 从 7.52% 升至 22.96%）；深度估计从灰度编码改为颜色编码时，几乎所有模型都退化为分割或直接复制，无论模型大小。这说明模型并非真正进行上下文推理，而是**依赖表层提示去“路由”到预训练见过的任务模式**。

3. **传统指标无法衡量“正确的上下文预测”**  
   在图像着色任务中，真正执行着色的 LVM 因像素级重建误差大而得分低于仅复制灰度图的 TinyVICL 或 Copy‑query 基线。LPIPS、SSIM 等指标无法区分“做得正确但颜色有偏差”与“什么都没做但保留了原始纹理”。

4. **模型规模不是突破 VICL 瓶颈的解药**  
   规模化并不能带来真正的自适应能力提升，当前 VICL 系统的“学习”更像是对任务编码和预训练任务分布的记忆，而非从少量示例中动态推导新任务。

### 优点
- **反直觉的实验设计**：用极端小模型作为“压力测试”工具，直接质疑了“越大越好”的流行假设，论据有力。  
- **系统化的偏移阶梯**：从数据分布偏移→任务编码偏移→全新任务，层次分明地揭示模型的自适应缺陷。  
- **提出 PaD 损失**：针对密集预测中的颜色保真问题，特别适用于需要精确颜色对齐的任务（如分割），在极小模型上实现了 16.8% 的分割 IoU 提升。  
- **定性与定量结合**：通过可视化暴露指标失灵，呼吁设计上下文敏感的评估方式。

### 不足与局限
- **任务覆盖和规模有限**：预训练仅使用 8 个任务和约 7 万张图像，可能无法代表更广泛的视觉任务多样性；对比的大模型可能在某些任务上并未充分优化。  
- **未提供新评估指标**：虽然深刻批评了现有指标的缺陷，但并未给出具体的改进方案或新的上下文感知评估协议。  
- **架构仅限于 Unet 变体**：没有探索 Transformer 或其他结构在同等小参数量下的表现，结论的适用范围可能受限于卷积架构。  
- **公平性讨论可以更深入**：对比的大模型未在相同数据上重新训练，但这是论文意图展示的现状，即现有模型面对新编码/新任务时表现不佳，这一设计本身是合理的，但若用于直接比较模型能力，则需注意其假设前提。
