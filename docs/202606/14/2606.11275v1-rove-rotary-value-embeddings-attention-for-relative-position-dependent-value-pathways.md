## 摘要
旋转位置嵌入（RoPE）使注意力分数具有位置相对性，但使值路径与位置无关：值标记发送的消息与其与查询的距离无关，均保持不变。我们提出RoVE，一种无需参数的修改，通过将值向量与键向量同时旋转，使值对位置敏感，并证明它将RoPE注意力转化为注意力卷积。这一新视角统一了计算机视觉、机器人学和现代大型语言模型架构中同一操作的几种独立表述。经过训练的124M和354M GPT-2模型在少样本上下文学习、分布外困惑度和长上下文检索任务上，相较于RoPE展示出一致的经验性提升，其中在需要长程聚合的任务上改进最为显著。

## Abstract
Rotary Position Embeddings (RoPE) make attention scores position-relative but leave the value pathway position-blind: the message sent by a value token is the same regardless of its distance from the query. We propose RoVE, a parameter-free modification that makes values position-sensitive by rotating them simultaneously with keys, and show that it turns RoPE attention into attentive convolution. This new perspective unifies several independent formulations of the same operation across computer vision, robotics, and modern LLM architectures. Trained 124M and 354M GPT-2 models show consistent empirical gains over RoPE on few-shot in-context learning, out-of-distribution perplexity, and long-context retrieval, with the clearest improvements on tasks that require long-range aggregation.

# 论文深度分析报告

### 1. 论文的核心问题与整体含义

*   **核心问题**：现有主流的旋转位置编码（RoPE）存在结构性不对称性。RoPE成功使注意力分数（决定“看哪里”）依赖于查询（Query）和键（Key）之间的相对位置，但其值（Value）通路是“位置盲”的。即，一个值令牌向其查询令牌传递的信息是固定不变的，与其距离查询的远近无关。这限制了模型对长距离依赖关系的建模能力，因为信息的聚合方式没有考虑空间距离。
*   **整体含义与研究动机**：该论文旨在补全RoPE的对称性，提出了RoVE方法。其核心动机是让注意力机制中的“信息聚合”（值通路）与“信息筛选”（注意力分数）一样，都具备相对位置感知能力。这不仅在直觉上更完备，也在理论上将RoPE注意力统一到“注意力卷积”框架下，解释了多个领域（计算机视觉、机器人、LLM）独立发现的相似操作背后的共同原理。

### 2. 论文提出的方法论

*   **核心思想**：RoVE的关键思想是对值向量施加与键向量完全相同的旋转操作，使其在聚合前被转换到查询的“参考系”中。最终的效果是将原本位置无关的值映射矩阵替换为一个依赖于相对偏移量的核函数族。
*   **关键技术细节与公式**：
    *   **标准RoPE注意力**：输出 `yi = Σ A(X)_ij * W_v * x_j`，其中`W_v`是所有位置共享的、与位置无关的值映射矩阵。
    *   **RoVE定义**：输出 `yi = R_i^{-1} * Σ A(X)_ij * R_j * W_v * x_j = Σ A(X)_ij * (R_{j-i} W_v) * x_j`。
    *   这里 `R_i` 是位置 `i` 的旋转矩阵。公式表明，通过旋转，一个依赖于相对偏移量 `δ = j-i` 的值传递核 `ψ_δ = R_δ * W_v` 替代了固定的 `W_v`。
    *   **关键性质**：它是一个无参数的修改，计算复杂度低（`O(nd)`），与FlashAttention等高效注意力内核兼容。
    *   **理论视角**：
        *   **注意力卷积**：RoVE将标准注意力转换为注意力卷积，其混合器矩阵具有块托普利茨（block-Toeplitz）结构，而非标准RoPE的克罗内克（Kronecker）结构。
        *   **电路框架分析**：在Transformer电路视角下，RoPE的QK（查询-键）和OV（输出-值）电路是解耦的。RoVE则赋予OV电路与QK电路对称的相对位置敏感性，使OV矩阵本身成为偏移量的函数，打破了原有的解耦结构。
