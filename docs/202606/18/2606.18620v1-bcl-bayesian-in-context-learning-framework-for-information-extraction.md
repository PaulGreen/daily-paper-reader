## 摘要
现有的信息抽取（IE）任务越来越多地采用基于大语言模型的上下文学习（ICL）。然而，当前方法在不同模型规模下表现不一致，或缺乏系统性优化和泛化能力。基于此，我们提出了BCL（用于信息抽取的贝叶斯上下文学习框架），这是首个利用粒子滤波与贝叶斯更新来系统优化跨IE任务标签表示的优化框架。通过初始化、观测、权重更新和重采样四个步骤，BCL可推广至序列标注和关系分类两种范式。大量实验表明，BCL相较于现有方法取得了显著且一致的性能提升。

## Abstract
Existing information extraction (IE) tasks increasingly adopt in-context learning (ICL) with large language models. However, current approaches either show inconsistent performance across model scales or lack systematic optimization and generalizability. Building on this, we propose BCL (Bayesian In-Context Learning Framework for Information Extraction), the first optimization framework that uses particle filtering with Bayesian updates to systematically refine label representations across IE tasks. Through four steps initialization, observation, weight update, and resampling, BCL generalizes to both sequence labeling and relation classification paradigms. Extensive experiments demonstrate substantial and consistent improvements over existing approaches.

### 1. 核心问题与研究动机

- **问题背景**：信息抽取（IE）任务日益依赖大语言模型（LLM）的上下文学习（ICL）。现有方法主要包括**任务转换法**（如 ChatIE、CodeIE，将 IE 转化为对话或代码生成任务）和**指南法**（如 GuideNER，为模型提供标注指南而非示例）。
- **关键痛点**：
  - 任务转换法在超大商业模型上可能有效，但在较小模型上性能严重退化（例如 ChatIE 在 Qwen‑2.5‑7B 上 NER 仅 25.64 F1，CodeIE 在 Llama‑3.1‑8B 上 RE 几乎为零）。泛化性差，难以在计算受限的实际场景中部署。
  - GuideNER 虽引入指南思路，但依赖简单的频率筛选，缺乏系统优化，且仅适用于 NER，无法扩展到关系抽取（RE）。
- **本文动机**：构建一个**系统化、可优化、跨 IE 范式通用**的 ICL 框架，通过贝叶斯推理与粒子滤波自适应地精炼标签表示，稳定提升不同模型规模下的 IE 性能。

### 2. 方法：BCL（Bayesian In‑Context Learning Framework）

- **核心思想**：将 IE 标签离散化为**语义原子单元（子类别）**，如将“Person”拆解为“athlete”“politician”等；将这些子类别规则视为**可控制的离散变量**，采用**粒子滤波 + 贝叶斯更新**迭代优化规则组合，形成适配具体数据集的标签表示。
- **控制论视角**：将 LLM 的 IE 过程视作一个输入‑输出系统，规则集合 \( R_t \) 为外部可控低维状态，通过观测 IE 性能 \( y_t \) 来更新状态，避免直接操控 LLM 内部参数。
- **四步粒子滤波流程**（图 3）：
  1. **初始化（粒子生成与先验）**  
     - 对训练样本使用 LLM 提取子类别规则作为初始粒子 \( p_i^{(0)} \)，每个粒子对应一个实体标签。  
     - 用**困惑度（PPL）**计算先验权重 \( w_i^{(0)} \)：PPL 越低，规则语言越自然，先验权重越高。
  2. **观测（评估）**  
     - 在训练验证批次上，计算每个粒子的**似然置信度** \( y_i^{(t)} \)：基于 LLM 使用该规则生成标签时的对数概率（长度归一化），反映规则实际表现。
  3. **权重更新（贝叶斯后验）**  
     - \( \tilde{w}_i^{(t)} = w_i^{(t-1)} \cdot \exp(\beta \cdot y_i^{(t)}) \)，再归一化。  
     - 本质：将先验信念（语言自然度）与实验证据（IE 性能）相乘得到后验。
  4. **重采样（多级策略）**  
     - 第一级：保留 Top‑50% 高权重粒子，去除低效粒子。  
     - 第二级：通过 LLM 对保留粒子进行**语义变异**（细化、泛化、语境化），生成新粒子，并基于 PPL 赋予新先验，维持种群多样性。
- **迭代终止**：当连续 3 轮验证 F1 相对提升 < 3%，或训练样本耗尽。

### 3. 实验设计

- **数据集**：覆盖两大 IE 范式的 6 个基准。
  - **NER**：CoNLL‑2003（新闻，4 类）、ACE 2005（新闻/会话，7 类）、GENIA（生物医学，5 类）。
  - **RE**：NYT（新闻，24 关系）、CoNLL04（通用，5 关系）、SciERC（科学，7 关系）。
- **评价指标**：实体级别 F1（NER 要求边界+类型完全匹配；RE 要求头尾实体与关系类型均匹配）。
- **对比方法**：
  - `One‑shot`：单一示例演示任务格式。
  - `ChatIE`：将 IE 转化为对话任务的零样本方法。
  - `CodeIE`：将 IE 转化为代码生成的方法。
  - `GuideNER`：当前最优的指南法，但仅限 NER。
- **模型**：Qwen‑2.5‑3B、Qwen‑2.5‑7B、Llama‑3.1‑8B、Pixtral‑12B，温度 0，种子 42 确保可重复。
- **超参数**：每类标签粒子数 10，选择压力 β=2，观测批次大小经网格搜索（1‑15 句）选定，重采样保留比 50%。

### 6. 主要结论与发现

- BCL 在所有 IE 基准上**一致地**超过所有基线，较 One‑shot 提升幅度显著（如 Qwen‑2.5‑7B CoNLL03 从 62.82 → 72.83 F1），在 RE 上解决先前任务转换方法近零分问题（如 NYT 从 0.28 → 0.43）。
- **数据效率极高**：仅用 3%‑5% 训练数据即可收敛，性能接近全量数据效果。
- **贝叶斯权重更新和多样性变异**是性能的核心驱动力，性能过滤主要起维持粒子紧凑、降低计算开销的作用。
- 学习到的规则具有**跨模型泛化性**：小模型优化的规则直接用于 GPT‑3.5‑turbo 仍能提升性能。
- 框架对长尾实体**鲁棒**，稀有实体 F1 与高频实体差异很小。

### 7. 优点与亮点

- **系统性优化框架**：首次将粒子滤波与贝叶斯推理系统引入 ICL‑IE，将问题从启发式选择提升到可推理的优化层面。
- **跨范式通用**：同时适用于 NER 和 RE，弥补了 GuideNER 等仅限 NER 的局限。
- **极高数据效率**：极小样本即可收敛，降低了对标注数据和计算资源的需求。
- **组件分工明晰**：通过消融实验清晰验证各部件的作用，设计有据可依。
- **模型无关性**：在 4 个不同架构、规模的模型上均有效，且规则可迁移至更强商用模型。
- **实验严谨**：大量跨数据集、跨模型、多维度分析，包含语义一致性、频率分层等深度诊断。

### 8. 不足与局限

- **优化阶段开销**：尽管数据用量少，但每轮观测需进行 LLM 推理评估，总迭代次数 \( K \times M \) 仍可能带来不可忽略的延迟，不适合频繁更新的场景。
- **对稀有实体的潜在偏差**：虽然频率分层分析显示影响不大，但粒子滤波倾向高频模式可能在更极端不平衡情况下放大偏差，论文未深入探讨。
- **任务覆盖**：实验聚焦 NER 和 RE，未涉及事件抽取、端到端联合抽取、跨语言等更复杂情形。
- **超参数依赖**：粒子数、β、观测批次大小等需网格搜索，增加了调参负担。
- **粒子质量受 LLM 生成能力制约**：子类别的语义合理性和变异的多样性仍依赖于底层 LLM 的能力。
- **未与微调方法对比**：仅与纯 ICL 方法比较，未说明与参数高效微调等方法的效果差距。
