## 摘要
上下文工程已成为无需更新参数即可改进AI系统的主要手段。最近的研究表明文本梯度并不像真实梯度那样发挥作用，这促使我们将自动提示优化（APO）视为黑盒搜索。我们引入了SPO（随机提示优化），一种在提示空间中进行随机搜索的框架，并比较了三种复杂度递增的策略：基于错误信息的随机搜索、带有进化算子的遗传算法，以及SAGE（通过智能体引导探索的SPO），一种包含诊断代码执行的多智能体流水线。在三个基准测试中，没有单一策略占主导地位；有效性取决于场景结构（景观结构）与错误类型的交互作用。我们进一步将SAGE部署在持续优化范式下的心理健康聊天机器人上，它将八个周期各自存在噪声的A/B测试融合为次日留存率具有统计显著性的提升。我们认为，将定性诊断与定量验证相结合，是智能体优化在开放式任务导向对话中有效的关键。

## Abstract
Context engineering has emerged as a primary lever for improving AI systems without parameter updates. Recent work showing that textual gradients do not function as real gradients motivates treating automatic prompt optimization (APO) as black-box search. We introduce SPO (Stochastic Prompt Optimization), a framework for stochastic search over prompt space, and compare three strategies of increasing sophistication: error-informed random search, a genetic algorithm with evolutionary operators, and SAGE (SPO via Agent-Guided Exploration), a multi-agent pipeline with diagnostic code execution. Across three benchmarks, no single strategy dominates; effectiveness depends on the interaction of landscape structure with error type. We further deploy SAGE on a mental-health chatbot under a continuous optimization paradigm, where it compounds eight cycles of individually-noisy A/B tests into a statistically robust gain in next-day retention. We argue that coupling qualitative diagnosis with quantitative validation is what makes agentic optimization effective for open-ended task-oriented dialogue.

### 2. 方法论：SPO 框架与 SAGE 智能体探索

- **问题形式化**：
  - 令 \(\mathcal{P}\) 为系统提示空间，\(\mathcal{D}\) 为任务数据集，奖励函数 \(R: \mathcal{P} \times \mathcal{D} \rightarrow [0,1]\)，目标为最大化期望奖励 \(\mathbb{E}_{x \sim \mathcal{D}}[R(p, x)]\)。
  - 该优化被视为**带噪声的黑盒优化**，评估昂贵且高噪声，但有效自由度低（语义上相似的提示表现也相近，呈现丰富的局部结构）。

- **共享框架：随机爬山**：
  - 所有策略采用相同的外循环：每轮生成 \(Q\) 个候选提示 \(S(p_k, \mathcal{D})\)，结合现有最佳提示 \(p_k\)，选择经验平均奖励最高的作为 \(p_{k+1}\)，保证单调不降。
  - $$p_{k+1} = \arg\max_{p \in \{p_k\} \cup S(p_k, \mathcal{D})} \hat{R}(p)$$

- **三种搜索策略**：
  - **SPO‑RS（残差搜索）**：基于错误信息的随机搜索，利用高温（τ=0.9）元模型，以当前最佳提示及其错误摘要为条件生成候选，强调多样性探索。
  - **SPO‑GA（遗传算法）**：引入进化算子，种群大小为 \(P\)，通过交叉（结合父母优势并针对共享失败模式）和变异（单一锦标赛父本的有目标改进）产生后代，温度较低（τ=0.7），平衡探索与针对性。
  - **SAGE（智能体引导探索）**：多智能体流水线，核心创新是**诊断性代码执行**。智能体拥有计算工具包（文件 I/O、Shell 执行、代码搜索），运行于结构化的评估数据集。流程包括：
    1. **分析者**：交叉分析多个提示的评估结果，生成 \(H\) 个错误模式假设。
    2. **编排者**：筛选出 \(I\) 个最具前景的假设。
    3. **调查者**（并行 \(I\) 个）：深度验证单一假设，执行精确计数和推理轨迹分析，输出可实施的修复建议。
    4. **生成者**（并行 \(Q\) 个）：根据调查报告生成完整改进后的提示。
  - **关键区别**：SAGE 的代码执行用于**统计诊断**（聚类错误、统计检验、识别过度出现的失败模式），而非过程性产物构建。

### 6. 主要结论与发现

- **无统一最优策略**：在不同基准上排名变化明显。SAGE 在需要追溯推理错误的 XBRL Formula 上领先；FiNER（平滑景观）上简单策略泛化更好；AppWorld（程序性错误）上 SPO‑GA 最佳。
- **景观结构不是唯一决定因素**：通过半变异函数分析，Formula 和 AppWorld 都呈现快速失相关的“崎岖”景观，但前者受益于诊断深度，后者受益于较简单的搜索。决定性因素是**错误类型**：级联推理错误需要根因分析，而程序性、按任务散落的错误用简单搜索即可。
- **持续优化可累积噪声信号**：在聊天机器人部署中，8 轮中仅 2 轮单独达到统计显著性，但链接各轮 A/B 增量后，次日留存率相对提升 **+29.4%**，且置信区间在第 5 轮后完全离开零点，说明将多个低功率试验链式累积可产生稳健的总效应。
- **定性诊断 + 定量验证是关键**：对于开放式、无明确对错信号的领域，SAGE 的代码执行能力使智能体能从数据中挖掘行为模式，量化其与下游指标的关系，从而实现有效的提示改进。

### 7. 优点

- **理论视角清晰**：将 APO 重新诠释为结构化黑盒搜索，并引入地统计学工具（半变异函数）量化提示空间的崎岖度，增强对优化难度的理解。
- **创新的智能体设计**：首次将代码执行用于**诊断性统计**，而非过程性构件生成，提升了错误分析的粒度与证据强度。
- **对照严谨**：三种策略共享框架，分离了探索方式与分析深度的影响，比较公平。
- **现实世界验证**：在生产级心理健康聊天机器人上持续部署，证明了方法在“信噪比低、目标信号延迟长”的开放域任务中的实用价值，超越静态基准。
- **实用启示**：“持续链接低功率 A/B 测试”的方法为难以进行大规模实验的系统提供了一条可行路径。

### 8. 不足与局限

- **评估函数依赖自动评测**：SPO 需要自动奖励函数，对于无清晰真实答案的任务，引入 LLM 裁判或人工评分会带来额外噪声和成本。
- **分布偏移**：持续优化假设过往数据的洞察在未来仍有效。用户群体和行为的演变可能导致增益递减，长期收敛性未验证。
- **创新受限**：由于基于历史对话诊断模式，SAGE 偏向优化已有行为，难以引入全新行为。深层次目标（如症状缓解）生成太慢，无法作为 A/B 测试目标。
- **元模型与目标模型的固定性**：实验仅使用 Claude Sonnet 4.6 作为元模型、DeepSeek‑V3.1 作为目标模型，未探讨不同模型组合对策略效果的影响。
- **未报告算力成本**：论文未给出计算资源详情，使复现成本和可扩展性难以评估。
- **奖励单调性风险**：爬山选择虽保证不退化，但可能陷入局部最优，尤其是在非凸景观中。
- **代理指标的使用**：在心理健康场景中，次日留存率是便捷代理，但可能与最终临床改善存在偏差，需谨慎解读。
