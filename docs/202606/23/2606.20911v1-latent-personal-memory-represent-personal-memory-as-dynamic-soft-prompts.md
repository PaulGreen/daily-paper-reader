## 摘要
个性化大型语言模型（LLM）需要以计算高效、可扩展且与冻结基础模型兼容的方式编码长期的、用户特定的行为模式。我们提出了潜在个人记忆（Latent Personal Memory，LPM），这是一个可扩展的框架，它将用户特定的历史表示为一个紧凑的、持久的矩阵，包含 N 个可解释的潜在槽位。一个共享的交叉注意力投影网络将这些槽位映射为动态的、以输入为条件的软提示，并预先添加到冻结 LLM 的输入之前。我们在 Qwen3-1.7B、4B 和 8B 的骨干网络上，使用 PersonaMem v1 和 LoCoMo 基准对 LPM 进行了评估。结果表明，在 PersonaMem v1 上，LPM 的整体准确率分别比 LoRA 和 Prompt Tuning 高出最多 8.8% 和 54.4%，同时将 KV 缓存使用量减少了 64 倍以上。在 LoCoMo 上，LPM 以少 120 倍的可训练参数达到了与 LoRA 相当的准确率。我们还表明，LPM 的效率随着上下文长度的增加而提高，并且在 128K 上下文长度下优于完整上下文。

## Abstract
Personalizing large language models (LLMs) requires encoding long-term, user-specific behavioral patterns in a way that is computationally efficient, scalable, and compatible with a frozen base model. We present Latent Personal Memory (LPM), a scalable framework that represents user-specific history as a compact, persistent matrix of N latent slots, that are interpretable. A shared cross-attention projection network maps these slots into dynamic, input-conditioned soft prompts that are prepended to the input of a frozen LLM. We evaluate LPM on PersonaMem v1 and LoCOMO benchmarks across Qwen3-1.7B, 4B, and 8B backbones. Results demonstrate that LPM outperforms LoRA and Prompt Tuning by up to 8.8% and 54.4% in overall accuracy respectively on PersonaMem v1, while reducing KV-cache usage by over 64x. On LoCoMo, LPM matches LoRA accuracy with 120x fewer trainable parameters. We also show that the efficiency of LPM grows with context length and outperforms full-context at 128K context length.

## 1. 论文核心问题与整体含义

- **研究背景**：大型语言模型（LLM）的个性化需要高效、可扩展地编码用户长期的行为模式与偏好，同时保持基座模型冻结不变。
- **现有方法的局限**：
  - 全上下文方法：在推理时拼接全部历史，带来极高的 KV 缓存和延迟成本。
  - RAG（检索增强生成）：需要维护随历史增长的外部索引，更新开销大。
  - 文本记忆方法：依赖外部结构化记忆或智能体架构，内存占用大，难以抽象偏好演化。
  - 参数高效微调（如 LoRA）：会直接修改模型权重，可能损害通用推理能力。
  - 提示调优（Prompt Tuning）：学习静态软提示，表达能力受限。
  - 上下文压缩方法：针对通用压缩，而非长期个性化。
  - 潜在记忆方法：通常需要大规模预训练或额外生成器，不可扩展且不具可解释性。
- **论文目标**：提出一种可扩展、高效、可解释的潜在记忆框架，将用户历史压缩为小型潜在槽位矩阵，并通过共享投影网络动态生成输入条件的软提示，在不修改基座模型的情况下实现个性化。

## 2. 方法论

### 核心思想
- 为每个用户维护一个**持久性潜在槽位矩阵** \(M_u \in \mathbb{R}^{N \times d_{mem}}\)（\(N\) 个槽位），通过训练学习，压缩用户完整对话历史。
- 用一个**共享交叉注意力投影网络**（所有用户共享参数），根据当前输入 \(x\) 从 \(M_u\) 动态生成软提示，再前置到冻结 LLM 的输入中。

### 关键技术细节
- **多头记忆机制**：使用 \(H\) 个独立的记忆头 \(M_u^h\)，每个头对应一个投影网络，公式如下：
  \[
  \tilde{P}_h = \text{softmax}\left(\frac{W_Q^h e(x) (W_K^h M_u^h)^\top}{\sqrt{d}}\right) W_V^h M_u^h
  \]
  其中 \(e(x)\) 为输入文本的嵌入（由小冻结嵌入模型得到）。
- **后处理**：每个头的输出 \(\tilde{P}_h\) 通过 MLP + LayerNorm 得到最终软提示 \(P_h(x, M_u^h)\)，然后将所有头的软提示拼接并前置到输入：
  \[
  \hat{y} = \text{LLM}_{\text{frozen}}([P_1; \dots; P_H; x])
  \]
- **训练方式**：
  - 用户历史按照固定大小的块（chunk）顺序处理，每个 chunk 使用前一个 chunk 生成的软提示进行下一 token 预测，防止未来信息泄露。
  - 损失函数：交叉熵损失 + 非对称熵正则项（防止注意力塌缩），公式为：
    \[
    \mathcal{L} = -\sum_i \log p(C_t^{(i)} \mid C_t^{(<i)}, P_{t-1}) + \alpha \cdot \max(0, H_{\text{target}} - H(a))
    \]
  - **训练流程**：在每个 epoch 内，逐用户逐块更新用户专属槽位（\(M_u\)），同时累积共享投影网络的梯度，在 epoch 结束时统一更新投影网络参数，避免噪声更新（见算法 1）。
- **推理**：仅用当前问题检索软提示，不携带历史，实现恒定 KV 缓存和低延迟。

## 3. 实验设计

  - **LoCoMO**：长期对话基准，平均上下文约 9K token，包含单跳、多跳、时态和开放域问题，1540 题。使用 GPT-5-mini 作为评判模型，通过二分类正确/错误评分。

## 6. 主要结论与发现

- LPM 在两个基准上均显著优于 LoRA 和 Prompt Tuning，尤其在偏好演化、偏好原因、新场景泛化等语义个性化问题上优势明显。
- 在 PersonaMem v1 (Qwen3-8B) 上，LPM 整体准确率 48.22%，比 LoRA 高 8.8%，比 Prompt Tuning 高 54.4%，且 KV 缓存减少 64 倍，延迟降低约 4.3 倍。
- 在 LoCoMO 上，LPM 用仅 0.65M 参数达到与 LoRA（77M）相似的准确率，参数少约 120 倍。
- 跨模型尺度（1.7B, 4B, 8B）LPM 均保持一致性优势，尤其小模型增益更大。
- 上下文扩展：当 PersonaMem 的上下文从 32K 增长到 128K 时，全上下文准确率降至 28.7%，而 LPM 稳定在 48.2% 左右，且资源消耗几乎不变。
- 通用能力保留：LPM 在 GSM-8K 和 MMLU 上保持与原模型相当的水平，未出现 LoRA 那样的轻微退化。
- 可解释性：UMAP 可视化显示不同用户的记忆槽位形成良好分离的簇，且基于定性评分准则发现，几何空间中的差异与行为模式的语义差异一致。

## 7. 优点

- **高效参数化**：每用户仅需约 65K 可训练参数（PersonaMem 设定），共享投影网络不随用户数量增长，适合大规模部署。
- **推理高效**：显著降低 KV 缓存、峰值内存和延迟，尤其在上下文极长时优势突出。
- **动态软提示**：同一记忆槽位可根据输入问题生成不同软提示，表达能力优于静态提示调优。
- **不修改基座模型**：基座 LLM 保持冻结，保护通用能力。
- **可解释性**：记忆槽位学习到行为特征，可用几何分析与定性评判验证。
- **训练简单**：无需预训练、无需额外生成器或 QA 数据集，仅用 next-token 预测即可。

## 8. 不足与局限

- **事实记忆能力弱**：LPM 在精确事实回忆（如日期、数字、人名）方面不如全上下文或 RAG，适宜抽象偏好但非精准记忆。
- **需要进一步处理事实知识**：论文建议未来采用混合方法（潜在记忆 + 显式事实缓存）来解决精确知识问题。
- **记忆粒度单一**：所有记忆头平等地编码长期与短期信息，未区分不同时间尺度，可能影响效率与效果，尚待研究结构化记忆。
- **复杂意图或少样本场景未覆盖**：论文仅评估了个性化 QA 任务，未涉及个性化对话生成、多轮交互等更复杂场景。
- **LoCoMO 上增益有限**：虽然参数高效，但与 LoRA 相比准确率仅持平，且均远低于全上下文（71.10%），说明在短上下文的生成式任务上 LPM 仍有提升空间。
- **可解释性研究规模较小**：仅对部分用户对进行了定性分析，结论的普适性有待更大规模验证。
