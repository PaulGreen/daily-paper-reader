## 摘要
单域泛化（SDG）旨在学习一个稳健的模型，使其在仅有一个源域可用于训练的情况下，仍能在许多未见域上表现良好。实现单域泛化的一个有前景的方向是通过数据增强或图像生成来产生域外（OOD）训练数据。鉴于人工智能生成内容（AIGC）的快速发展，本文首次提出利用强大的预训练文本到图像（T2I）基础模型来创建训练数据。然而，为所有可能的域手动设计文本提示来生成图像往往不切实际，且某些域特征可能过于抽象而难以用文字描述。为应对这些挑战，我们为预训练扩散模型提出了一种新颖的渐进式对抗提示微调（PAPT）框架。我们的方法不依赖静态文本域，而是学习两组抽象提示作为扩散模型的条件：一组捕获域不变的类别信息，另一组则建模域特定的风格。这种对抗学习机制使T2I模型能够生成多种域风格的图像，同时保留关键的类别特征。大量实验证明了所提方法的有效性，其性能优于当前最先进的单域泛化方法。

## Abstract
Single domain generalization (SDG) aims to learn a robust model, which could perform well on many unseen domains while there is only one single domain available for training. One of the promising directions for achieving single-domain generalization is to generate out-of-domain (OOD) training data through data augmentation or image generation. Given the rapid advancements in AI-generated content (AIGC), this paper is the first to propose leveraging powerful pre-trained text-to-image (T2I) foundation models to create the training data. However, manually designing textual prompts to generate images for all possible domains is often impractical, and some domain characteristics may be too abstract to describe with words. To address these challenges, we propose a novel Progressive Adversarial Prompt Tuning (PAPT) framework for pre-trained diffusion models. Instead of relying on static textual domains, our approach learns two sets of abstract prompts as conditions for the diffusion model: one that captures domain-invariant category information and another that models domain-specific styles. This adversarial learning mechanism enables the T2I model to generate images in various domain styles while preserving key categorical features. Extensive experiments demonstrate the effectiveness of the proposed method, achieving superior performances to state-of-the-art single-domain generalization approaches.

### 2. 论文提出的方法论

- **核心思想**：本文提出**渐进式对抗提示微调（Progressive Adversarial Prompt Tuning, PAPT）**框架，核心是学习两组可训练的抽象提示向量，作为扩散模型的条件输入：
  - **类别提示（Category Prompt）**：捕获跨域不变的类别语义信息。
  - **域提示（Domain Prompt）**：建模域特定的风格（包括难以用文字表达的抽象风格）。
- **关键技术细节**：
  - **第一阶段：类别提示微调（Category Prompt Tuning）**  
    为每个类别 `k` 学习一个可学习的提示嵌入 `E^c_k`，将其与文本编码器的输出拼接，通过扩散模型的去噪损失（LDM loss）进行优化，使类别提示能够表征域不变的类别特征。优化目标为：
    \[
    \mathcal{L}_{\mathrm{LDM}} = \mathbb{E}_{f_E(x), y, \epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \hat{\epsilon}\|_2^2 \right]
    \]
  - **第二阶段：对抗性域提示微调（Adversarial Domain Prompt Tuning）**  
    初始化一个域提示记忆库 `P`（由少数几个手动设计的文本域提示嵌入初始化）。对于新学习的域提示 `E^o_d`，利用扩散模型生成潜在表示 `z_0`，然后通过如下损失函数进行对抗训练：
    \[
    \mathcal{L}_{\text{domain}} = -\sum_{i=1}^N \log p^i_d(z_0; \Phi(w^i_d))
    \]
    \[
    \mathcal{L}_{\text{class}} = -\log p^k_c(z_0; \Phi(w^k_c))
    \]
    \[
    \mathcal{L}_{\text{all}} = \mathcal{L}_{\text{class}} + \lambda \mathcal{L}_{\text{domain}}
    \]
    其中，`p^i_d` 表示 `z_0` 属于记忆库中第 `i` 个域风格的概率（通过余弦相似度和 softmax 计算），`p^k_c` 表示其属于第 `k` 个类别的概率。`\mathcal{L}_{\text{domain}}` 鼓励新域的风格与记忆库中已有域尽量不同，而 `\mathcal{L}_{\text{class}}` 则确保生成图像仍保留正确的类别语义。为了高效计算梯度，采用一步近似从噪声隐变量 `z_t` 估计 `z_0`。
  - **第三阶段：渐进式训练方案（Progressive Training Scheme）**  
    每经过一定迭代次数，将新学习到的域提示 `E^o_d` 加入记忆库 `P`（即 `P \leftarrow P \cup \{E^o_d\}`）。下一次训练时，新的域提示会与记忆库中不断增长的风格集合进行对抗，从而逐步扩充生成域的多样性，并覆盖更多接近分类边界的困难样本。

### 8. 不足与局限：包括实验覆盖、偏差风险、应用限制等

- **依赖预训练模型质量**：方法高度依赖预训练 T2I 扩散模型的能力，生成图像的质量和内容受限于基模型的知识边界，当基模型对特定域理解不足时可能失效。
- **计算与存储开销**：训练过程中需要反复调用扩散模型进行生成和梯度反向传播（即使是单步近似），实际训练成本未与纯增强方法进行量化比较；域记忆库的逐步扩张也会增加计算和存储负担。
- **域提示大小固定**：域提示数量 `N` 需要预先设定，且实验中仅测试到 5 个学习域，对于极大规模或高度异构的目标域集合，其扩展性和覆盖能力有待验证。
- **评价维度单一**：仅通过分类准确率评估生成域的质量，缺乏对生成图像的真实性、多样性以及分布外覆盖度的直接度量。
- **偏差风险**：域提示记忆库采用手工设计的文本域进行初始化，尽管消融实验显示影响不大，但这种初始化选择可能引入对特定风格的人为偏好，在更广泛的真实场景中仍需谨慎。
- **应用限制**：当前验证集中在图像分类，对于目标检测、分割等更复杂的视觉任务，该生成框架能否直接迁移仍需进一步研究。
