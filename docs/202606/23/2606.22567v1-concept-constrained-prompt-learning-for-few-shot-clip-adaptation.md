## 摘要
少样本提示学习是将CLIP适配到下游任务的有效策略，但仅针对类别的提示优化会过拟合基类监督，削弱对新类的迁移能力。我们提出了概念约束提示学习（CCPL），一种轻量级正则化框架，通过将可学习的类别提示锚定到冻结的概念级文本原型上，而无需更新CLIP编码器。CCPL学习一组共享的上下文令牌，通过附加类别名称来实例化类别提示，并从类别级概念库中构建冻结的概念原型。在训练期间，文本空间余弦一致性目标将可学习的类别提示嵌入与冻结的概念原型对齐；概念丢弃通过防止过度依赖固定的概念列表提供额外的正则化。在推理时，CCPL可选地使用可控的集成权重α融合类别提示对数几率与概念原型对数几率。我们的默认配置使用文本空间概念正则化λ = 0.5、概念丢弃p = 0.3以及较弱的概念引导融合（α = 0.1），没有基于KL的预测一致性项。在相同的自动生成回退划分下的实验表明，与CoOp相比，CCPL在DTD（+0.6）和EuroSAT（+2.9）上提升了基类到新类的调和平均数，同时在OxfordPets上接近中性（-0.1）。消融研究表明，文本空间概念正则化持续有益，而最佳的概念引导推理强度取决于数据集和协议。这些结果表明，当概念原型与数据集语义自然对齐时，概念约束最为有效，并识别出细粒度类别是当前的边界条件。代码发布于：https://github.com/richael-sang/concept-constrained-prompt-learning。

## Abstract
Few-shot prompt learning is an effective strategy for adapting CLIP to downstream tasks, but class-only prompt optimization can overfit base-class supervision and weaken transfer to unseen classes. We propose Concept-Constrained Prompt Learning (CCPL), a lightweight regularization framework that anchors learnable class prompts to frozen concept-level text prototypes without updating CLIP encoders. CCPL learns a set of shared context tokens, instantiates class prompts by appending class names, and constructs frozen concept prototypes from a class-level concept bank. During training, a text-space cosine consistency objective aligns learnable class-prompt embeddings with frozen concept prototypes; concept dropout provides additional regularization against over-reliance on fixed concept lists. At inference, CCPL optionally fuses class-prompt logits with concept-prototype logits using a controllable ensemble weight alpha. Our default configuration uses text-space concept regularization lambda = 0.5, concept dropout p = 0.3 and weak concept-guided fusion (alpha = 0.1), with no KL-based prediction consistency term. Experiments under identical automatically-generated fallback splits show that CCPL improves the base-to-new harmonic mean on DTD (+0.6) and EuroSAT (+2.9) compared with CoOp, while remaining near-neutral on OxfordPets (-0.1). Ablations indicate that text-space concept regularization is consistently beneficial, while the best concept-guided inference strength is dataset- and protocol-sensitive. These results suggest concept constraints are most effective when concept prototypes align naturally with dataset semantics, and identify fine-grained categories as a current boundary condition. The code is released at: https://github.com/richael-sang/concept-constrained-prompt-learning.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**: 在少样本场景下，将预训练的视觉-语言模型（如CLIP）适配到下游任务时，流行的**提示学习（Prompt Learning）方法（如CoOp）存在严重的过拟合风险**。具体表现为，通过在少量基类数据上优化文本提示，模型在基类上的准确率可能提升，但对未见过的新类泛化能力（即开放词汇能力）会显著下降。
- **研究动机**: 这种“基类-新类权衡”（base-new trade-off）的根本原因在于，仅使用简短、语义稀疏的类别名称（如“编织”、“森林”）进行提示优化，会驱使文本嵌入偏离CLIP原本编码的、富含语义和视觉线索的方向。尤其是对于纹理、场景等类别，单纯的类别名缺乏丰富的描述性视觉属性（如材质、图案、布局等）。
- **整体含义**: 本文旨在解决这一过拟合问题，提出一种轻量级的正则化框架。其核心思想是，如果能为每个类别编译一组描述性的概念短语，并将其作为**冻结的语义“锚点”**来约束可学习提示的优化过程，就能鼓励模型保持与预训练知识的语义对齐，从而在提升基类性能的同时，保留甚至提升对新类的泛化能力。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

论文提出了**概念约束提示学习（Concept-Constrained Prompt Learning, CCPL）**，一个在不增加可训练参数的前提下，将概念级语义锚点引入提示学习的正则化框架。其核心方法论如下：

- **核心思想**:
  - **文本空间锚定**: 将可学习的类别提示文本嵌入，约束在与任务相关的、由人工构建的概念短语生成的冻结文本原型附近。
  - **训练-推理解耦正则化**: 训练时通过损失函数施加约束，推理时提供可选的概念引导对数几率融合，实现灵活控制。

- **关键技术细节**:
  - **类别提示参数化**: 沿用CoOp风格，学习一组共享的上下文令牌（Context Tokens），并附加真实的类别名。
  - **概念原型构建**:
    - 从一个**手工构建的概念库（Concept Bank）**中，为每个类别`c`提取`K_c`个描述性概念短语（例如，对“森林”类别的短语：“茂密的树冠”、“林地区域”、“绿色植被”）。
    - 使用**冻结的CLIP文本编码器**提取这些短语的归一化嵌入，然后进行**平均**和**二次归一化**，形成一个单一的、代表该类语义的**冻结概念原型向量 `tcon_c`**。
  - **概念丢弃（Concept Dropout）**: 训练时，以概率 `p=0.3` 随机掩蔽部分概念短语，防止模型过度依赖特定的概念表述，增强鲁棒性。
  - **文本空间概念正则化**: 核心的损失函数项 `L_text`。它计算**可学习的类别提示嵌入**与（经丢弃后的）**概念原型**之间的**余弦相似度损失**，从而对齐两者。
    - `L_text = (1/|C_base|) * Σ_{c in C_base} (1 - cos(tcls_c(θ), tcon_c))`
  - **训练目标**: 最终损失由标准的交叉熵分类损失和概念正则化损失加权求和得到： `L_CCPL = L_ce + λ_text * L_text`（默认`λ_text`=0.5）。
  - **概念引导推理**: 测试时，将最终预测的对数几率设定为**类别提示对数几率**（`zcls`）和**概念原型对数几率**（`zcon`）的凸组合：`z_i = (1 - α) * zcls_i + α * zcon_i`。权重 `α=0.1` 提供了微弱但有益的概念引导。

- **算法流程**:
  1. 初始化共享上下文令牌；预计算所有类别的概念原型。
  2. **训练循环**：对每个基类小批量数据，计算图像特征、类别提示嵌入和（经概念丢弃的）概念原型；计算分类损失 `L_ce` 和概念一致性损失 `L_text`；仅更新上下文令牌。
  3. **推理**：使用完整的（无丢弃）概念原型，根据公式 `zi = (1-α)zcls_i + αzcon_i` 计算最终预测。
