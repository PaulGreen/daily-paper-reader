## 摘要
部署在异构NLP任务上的微调编码器面临三个叠加问题：不匹配的归纳偏置、类别不平衡对特征统计量的破坏，以及缺乏根据外部词汇知识调节注意力的机制。我们提出了SURGELLM，一个统一的Transformer框架，通过专用的轻量级模块解决每个问题：外科手术式特征门控（在精选的词汇指示符和[CLS]上学习每个维度的sigmoid函数；当特征无信息时可证明地退化为恒等映射）、任务条件前缀令牌（将量化的特征值和任务标识符添加到每个输入前），以及实例加权归一化（IWN；从门控统计量中移除类别先验偏置）。我们证明了一个超额风险界，将门控收益与外科手术式特征对齐联系起来。在四个任务（SST-2、多跳检索、大语言模型提示归因和作者检测）上，涵盖17,830个示例和三个随机种子上的十一种模型变体，IWN变体取得了宏观F1分数0.940（比最强的非IWN基线高+0.036；在作者检测上高+0.130）。随机词汇表对照实验（平均F1下降-0.028）证实了收益来自词汇而非参数。我们发布了代码、词汇表和一个99.5%恢复率的自动提取配方。

## Abstract
Fine-tuned encoders deployed across heterogeneous NLP tasks face three compounding problems: mismatched inductive biases, class-imbalance corruption of feature statistics, and no mechanism to condition attention on external lexical knowledge. We introduce \textbf{\surgellm}, a unified transformer framework that addresses each with a dedicated lightweight module: a \emph{surgical feature gate} (learned per-dimension sigmoid over curated lexical indicators and \texttt{[CLS]}; provably degenerates to identity when features are uninformative), \emph{task-conditioned prefix tokens} (quantized feature values and task identity prepended to every input), and \emph{Instance-Weighted Normalization} (IWN; removes class-prior bias from gate statistics). We prove an excess-risk bound linking gate benefit to \emph{surgical feature alignment}. Across four tasks, SST-2, multi-hop retrieval, LLM-prompt attribution, and authorship detection, covering 17,830 examples and eleven model variants over three seeds, the IWN variant achieves macro-F1 \textbf{0.940} ($+0.036$ over the strongest non-IWN baseline; $+0.130$ on authorship detection). A random-vocabulary control ($-0.028$ avg.\ F1) confirms gains are lexical, not parametric. Code, vocabularies, and a $99.5\%$-recovery auto-extraction recipe are released.

### 1. 核心问题与整体含义（研究动机和背景）

- **多任务微调编码器的固有缺陷**：在异构自然语言处理（NLP）任务上部署微调编码器时，面临着三个相互叠加的严重问题：
  - **归纳偏置不匹配**：不同任务在词汇、标签空间和语域上差异巨大，直接共享参数会导致任务间相互干扰。
  - **类别不平衡损害特征统计**：数据集的类别分布严重偏斜（例如作者检测任务原始偏斜比高达9.3:1），会使全局标准化特征偏向多数类，削弱对少数类的判别能力。
  - **缺乏外部词汇知识融合机制**：微调后的模型无法有效利用超越上下文窗口的全局统计信息（如标点密度、词频等），而这些信息对于风格分析、作者检测等任务至关重要。
- **核心动机**：设计一个统一的轻量级框架，在不显著增加参数量的前提下，将精选手工词汇特征与Transformer编码器进行有效融合，并解决由类别不平衡导致的特征统计失真问题。

### 2. 方法论：核心思想与关键技术

- **统一框架SURGELLM**：通过三个专用模块，插件式地嵌入任何HuggingFace编码器背后。
  - **手术特征门控（Surgical Feature Gate）**：
    - 首先，从完整文本中提取一个**16维外科手术式特征向量**，包含10组精心筛选的词汇指示符（如情感极性词、LLM风格词、个人化用语等）以及6个表层统计特征（总词数、平均词长、句子数等）。
    - 特征向量经过**ReLU投影**后，与任务条件增强后的`[CLS]`表征进行拼接，再通过一个可学习的**逐维度Sigmoid门控**进行融合。
    - 门控输出控制原始编码表征与投影特征在不同维度上的混合比例，实现细粒度的跨模态融合，并在融合后应用层归一化。
  - **任务条件前缀令牌（Task-Conditioned Prefix Tokens）**：
    - 在每个输入文本前插入结构化前缀，显式声明任务ID和量化后的特征值。这些前缀令牌参与所有层的自注意力计算，让底层网络就能感知到词汇特征与上下文的关系，与仅作用于最终`[CLS]`层的门控机制形成互补。
  - **实例加权归一化（Instance-Weighted Normalization，IWN）**：
    - **病理根源**：在类别严重偏斜的数据上，全局均值和标准差会严重偏向多数类分布，导致门控输入偏离少数类的真实统计特性。
    - **解决方案**：在标准化过程中，用**类别平衡的均值和标准差**取代全局统计量。这些统计量仅在训练时从训练集类条件数据中计算得到，测试时直接使用，无需任何测试标签，且不引入任何额外可学习参数。
    - 该归一化方法在类别平衡时会自动退化为标准归一化，并能与其他处理不平衡的方法（如Focal Loss）组合使用。
- **理论保证**：
  - 定义了**手术特征对齐度**，并证明了**超额风险界**：门控带来的收益与特征对齐度正相关。
  - 证明了**零对齐下的安全性**命题：当特征无信息（对齐度为零）时，在权重衰减作用下，门控将自然退化为恒等映射，不会损害模型表现。

### 3. 实验设计

- **任务与数据集**：构建了一个包含四个异构任务、共计17,830个样例的评测套件，以替换传统单一或同质化的评测基准。
  - **D1（情感分析）**：SST-2，标准GLUE二分类电影评论情感数据集。
  - **D2（多跳检索）**：HotPotQA，多跳问答数据集，通过是否存在归因短语构造二分类任务。
  - **D3（LLM提示归因）**：LLM-7，判断文章是由LLM还是人类根据特定提示生成的。
  - **D4（作者检测）**：HumLLM，判断文本是人类还是LLM撰写，原始偏斜比9.3:1，是考查不平衡处理的核心任务。
- **对比基准**：
  - **基线模型**：DistilBERT、BERT、RoBERTa、ALBERT四种编码器的标准微调版本。
  - **变体模型**：对SURGELLM框架进行分模块消融，衍生出`SURGELLM-G`（仅前缀）、`SURGELLM-S`（前缀+门控）、`SURGELLM-FULL`（前缀+门控+扩展训练）以及最终的`SURGELLM-IWN`（加入IWN）。
  - **统一文本到文本模型**：T5-base，作为编码器-解码器架构的代表。
- **评估指标**：宏观F1分数（Macro-F1）作为核心指标，并辅以准确率、精度、召回率和ROC-AUC。所有结果报告为三个随机种子（{0,1,2}）上的均值±标准差，并通过Welch's t检验、Benjamini-Hochberg校正、95%自助抽样置信区间进行统计显著性检验。

### 6. 主要结论与发现

- **IWN是关键突破**：实例加权归一化（IWN）几乎完全逆转了严重类别不平衡对特征门控的负面影响。相比无IWN版本，它使作者检测任务（D4）的宏观F1提升了**+0.130**（绝对值），这是整个研究中最大的单点增益。
- **SURGELLM-IWN效果最优**：最终方案`SURGELLM-IWN-RoBERTa`在全部四个任务上的平均宏观F1达到**0.940**，比最强的同类非IWN基线高出**+0.034**，比标准微调RoBERTa高出**+0.036**。
- **增益本质源于词汇内容**：随机词汇对照实验导致F1平均下降-0.028，而通过自动提取方法生成的词汇表恢复了手工精选词汇表**99.5%**的性能，这双重验证了增益来自词汇知识的有效性，且手工步骤并非必需。
- **门控与前缀机制互补**：前缀主要负责在底层提供局部词汇线索（如检索任务），而门控在顶层调节整体风格（如作者检测），单独移除任何一方都会导致性能下降。
- **T5并非最优**：在该异构任务集上，220M参数的T5-base性能（0.897）不如125M的SURGELLM-IWN-RoBERTa，且计算开销更大，表明在固定参数预算下，专门设计的分类编码器架构比通用的序列到序列模型更高效。
- **理论一致性**：实验结果与理论证明高度吻合。任务的特征对齐度越高，IWN或门控带来的增益越大；而低对齐任务则观察到增益微小，门控无害退化。

### 8. 不足与局限

- **语言与模型规模限制**：所有核心实验仅限于**英文**文本和**基础规模的编码器**（11M至220M参数）。尽管在附录中给出了法文和德文的初步实验结果，并讨论了扩展到LLaMA的设想，但实际验证仍属不足。

- **任务覆盖面**：有意避开GLUE/SuperGLUE这类同质化套件，聚焦于四个高度异构的任务。这虽然凸显了方法的针对性，但也意味着方法在更广泛的标准任务上的适用性尚未被大规模检验。
- **失败案例分析**：尽管进行了定性失败分析（如对讽刺、否定、超短文本的无力），并指明了未来工作方向（长度条件的门控、对抗鲁棒性），但**未提出即时有效的解决策略**，目前仍属能力边界说明。
- **特征依赖**：方法的核心增益依赖于精心设计的词汇指示组。虽然提供了自动提取配方，但该配方的效果高度依赖于源任务训练数据的分布和规模，在没有合适种子语料的新领域或极低资源场景下，其有效性存疑。
