## 摘要
对于身处多步交互环境的大语言模型智能体而言，一个关键挑战是如何有效利用积累的交互经验。现有工作通常将这类经验的用途割裂为两种：将其作为自然语言规则放在模型外部供后续提示使用，或利用轨迹与反馈来更新模型参数。前者易于解释，但可能与不断演化的策略脱节；后者能更广泛地优化策略，但在稀疏奖励场景下对局部错误的纠正能力有限。我们提出 LLM 智能体经验规则与策略联合学习框架（JERP），该框架从相同的交互轨迹中同时更新长期经验规则库和策略。在决策时刻，JERP 检索与任务相关的规则，并基于这些规则与交互历史对智能体进行条件化。每个回合结束后，JERP 利用收集到的轨迹来优化策略，并通过将当前执行轨迹与参考成功轨迹进行对比来修订规则库。这种耦合使得规则库与演化的策略保持对齐，同时让稳定有效的行为逐步内化到模型本身。在 AlfWorld 和 WebShop 上的实验表明，JERP 在复杂交互任务的决策表现上带来了一致的提升。

## Abstract
For LLM agents in multi-step interactive environments, a key challenge is to make effective use of accumulated interaction experience. Existing work has typically separated two uses of such experience: keeping it outside the model as natural-language rules for later prompting, or using trajectories and feedback to update the model parameters. The former is easy to interpret but can fall out of sync with the evolving policy; the latter improves the policy more broadly but provides only limited correction for local mistakes in sparse-reward settings. We present Joint Learning of Experiential Rules and Policies for LLM Agents (JERP), which updates a long-term experiential-rule pool and the policy from the same interaction trajectories. At decision time, JERP retrieves task-relevant rules and conditions the agent on them together with the interaction history. After each episode, it uses the collected trajectories both to optimize the policy and to revise the rule pool by comparing current rollouts with reference successful trajectories. This coupling keeps the rule pool aligned with the evolving policy while allowing stable and effective behaviors to be gradually absorbed into the model itself. Experiments on AlfWorld and WebShop show that JERP yields consistent gains in decision performance for complex interactive tasks.

### 2. 方法论

- **核心思想**
  - 维护一个动态的**长期经验规则池**，在每个回合开始时根据任务检索出**工作规则集**，将其与任务描述、交互历史一同输入策略模型。
  - 同一批采样的轨迹既用于**群组相对策略优化**，也用于**对比反思式规则更新**，实现“一次采样、双重利用”。
- **关键技术细节**
  - **规则池结构**
    - 每条规则包含文本内容 `zi` 和效用分数 `si`。
    - 在决策时，仅选取分数最高的前 `k` 条规则作为当前回合的工作规则集，避免上下文过长。
  - **策略优化部分**
    - 基于 **GRPO** 的群组相对优势估计：对同任务的 N 条轨迹，根据环境奖励进行标准化计算优势 `Ai`，整条轨迹共享同一优势。
    - 优化目标包含 PPO 式裁剪与参考模型的 KL 正则项，使用 LoRA 进行参数高效微调。
  - **经验规则更新部分**
    - 采用**对比反思**机制：将当前轨迹群、参考成功轨迹、以及当前规则池共同输入冻结参数的 LLM，生成结构化的规则级编辑操作。
    - 定义了五种基本操作：**ADD**（新增）、**EDIT**（修订）、**UPVOTE** / **DOWNVOTE**（增强/削弱）、**MERGE**（合并语义重叠规则），系统按操作和预设步长自动更新规则与效用分。
    - 效用分低于阈值的规则会被淘汰，控制规则池容量并移除低价值信息。
    - 若当前任务尚未积累成功轨迹，则仅基于当前轨迹群与旧规则进行更新。
- **算法流程**
  - 训练每次外循环：采样任务 → 保留旧策略参数 → 从规则池选取工作规则集 → 采样 N 条交互轨迹 → 基于轨迹奖酬计算群组优势 → 用 GRPO 型损失更新策略参数 → 调用规则编辑操作更新规则池 → 将成功轨迹纳入参考集。

### 6. 主要结论与发现

- **性能提升**
  - JERP 在两个环境上的整体完成率和成功率均优于所有基线（AlfWorld 整体成功率 61.5%、WebShop 成功率 64.1%）。
- **增益来源**
  - 在需要更长操作序列、更多中间约束的子任务上（AlfWorld 的 Clean、Heat、Cool、Pick2），JERP 的提升更显著。这表明规则池在不断学习过程中保存了可复用的操作模式，为更复杂的任务提供了定向的决策支持。
- **协同进化作用**
  - 消融实验显示，固定规则池的变体在训练后期提升缓慢，而 JERP 通过持续修订规则池使其与不断变化的策略保持同步，进而推动性能持续上升。
  - 策略参数更新是性能提升的主要驱动力，而动态规则池则在保持对局部任务特定准则的关注上发挥“修正”作用，二者互补。

### 7. 优点

- **核心创新性设计**
  - 将经验规则维护与策略参数更新**纳入同一学习循环**，打破了两类既有派系各自为政的局面，保证了规则与策略的一致性。
- **规则池的动态管理**
  - 引入五种结构化编辑操作和效用评分机制，支持规则的增加、修订、合并与淘汰，实现了在训练中自动化、可解释的经验知识维护。
- **简洁且可复用的框架**
  - JERP 构建在成熟的 GRPO 策略优化方法之上，只增加了规则池及其对比更新的轻量模块，对于只需要少量额外计算即可增强现有 RL 训练 pipeline 具有较强实用性。
- **验证维度丰富**
  - 涵盖多类型任务（操作与购物），且既有主要结果对比，也通过消融实验验证了持续更新的规则池是不可或缺的部件。

### 8. 不足与局限

- **实验范围偏窄**
  - 仅选取了两个交互式基准（AlfWorld, WebShop），尚未在更多样化的环境（如开放型工具使用、多智能体场景）中验证。
- **规则选择策略较为简单**
  - 当前仅是按效用分排序取 top‑k，并不包含基于当前实例特定状态的更精细语义检索，可能在无关规则占比高时造成干扰。

  - 规则更新依赖一个外部冻结模型进行文本对比与分析，在长序列策略训练中会累积较多调用成本，且其效果受限于该模型的分析质量。
