## 摘要
音频-语言模型（ALMs）通过将音频与文本类别描述对齐，展现出强大的零样本性能。虽然提示学习通过少量样本的有监督适应提高了基类的准确率，但我们观察到一个关键的权衡：它常常降低新类的性能，有时甚至低于零样本准确率。这暴露了ALMs提示学习中从基类到新类的泛化差距。为解决这一问题，我们提出ZEBRA（零样本熵正则化提示学习，用于基类到新类泛化），这是一个即插即用的框架，融合了零样本逻辑值与提示学习逻辑值，并采用自熵正则化来减少对基类的过拟合。在多个音频分类数据集上的实验表明，ZEBRA在保持强大基类准确率的同时，持续提升新类性能，与标准提示学习相比，显著缩小了基类到新类的差距。代码见：https://github.com/asif-hanif/zebra。

## Abstract
Audio-Language Models (ALMs) achieve strong zero-shot performance by aligning audio with textual class descriptions. Although prompt learning improves accuracy on base classes through few-shot supervised adaptation, we observe a critical trade-off: it often degrades performance on novel classes, sometimes falling below zero-shot accuracy. This exposes a base-to-novel generalization gap in prompt learning for ALMs. To address this issue, we propose \textbf{ZEBRA} (Zero-shot Entropy-Regularized Prompt Learning for Base-to-Novel Generalization), a plug-and-play framework that fuses zero-shot logits with prompt-learning logits, and employs self-entropy regularization to reduce overfitting to base classes. Experiments across multiple audio classification datasets show that ZEBRA consistently improves novel-class performance while maintaining strong base accuracy, significantly reducing the base-to-novel gap compared to standard prompt learning. The code is available at: https://github.com/asif-hanif/zebra.

- 本文旨在**在不引入额外可训参数、不显著增加计算开销的前提下**，缓解这一泛化退化问题，使提示学习在增强基类的同时保留甚至改善对新类的识别能力。

## 二、论文提出的方法论

- **总体设计**：ZEBRA 是一个即插即用的框架，无需修改现有提示学习方法的内部结构，完全作用于输出层。
- **零样本逻辑融合**：
  - 将原始零样本模型的 logits \(f_{zs}(x)\) 与提示学习模型输出的 logits \(f_{pr}(x;\phi)\) 进行加权融合：
    \[
    f_{zebra}(x; \phi) = \lambda_{zs} \cdot f_{zs}(x) + \lambda_{pr} \cdot f_{pr}(x; \phi)
    \]
  - 其中 \(\lambda_{zs}\) 与 \(\lambda_{pr}\) 控制两部分贡献（论文设为 0.5 和 0.5），由此约束模型围绕原始零样本决策空间进行适应，而非完全偏离。
- **自熵正则化**：
  - 基于融合 logits 的 softmax 概率分布 \(p(x)\)，计算自熵：
    \[
    L_{ent} = -\sum_i p_i(x) \log p_i(x)
    \]
  - 最终的训练损失为交叉熵损失与自熵损失的组合（最小化交叉熵的同时最大化自熵）：
    \[
    L_{zebra}(x, y; \phi) = L_{ce}(f_{zebra}, y) - \lambda_{ent} \cdot L_{ent}(\text{softmax}(f_{zebra}))
    \]
  - 通过增大预测分布的熵，抑制模型对基类的过度自信，避免过拟合，从而提升对新类的泛化。
- **推理流程**：
  - 推理时仅使用融合 logits 取 argmax 得到预测类别，不再施加熵正则项。
- **高效率特点**：
  - 零样本 logits 只需计算一次，训练和推理中直接复用，无需额外通过文本编码器的前向传播，因此几乎没有增加可训参数和计算开销。
