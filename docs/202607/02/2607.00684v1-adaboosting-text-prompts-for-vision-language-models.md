## 摘要
预训练视觉-语言模型的分类精度依赖文本提示的质量。手工设计的模板和大语言模型生成的描述不仅使预测更具可解释性，还能在异构视觉-语言模型之间复用相同的提示。近期工作利用少量标注图像构建任务自适应的文本提示。然而，现有的少样本文本提示方法在构建提示时并未明确关注误分类样本，导致即便提供更多样本，性能提升也微乎其微。为充分利用少样本监督信号，我们提出文本提示增强（TPB），一个受AdaBoost启发的框架，将每个基于文本提示的分类器视为弱学习器，通过明确针对困难的误分类样本，将它们依次聚合成强集成。大量实验表明，TPB保留了文本空间中任务内在的、模型无关的线索，实现了稳健的跨模型迁移。在十一项分类基准上，TPB提升了源模型的准确率，并在迁移到更大、更强的视觉-语言模型时保持了随样本数量增加的增益，而现有方法难以维持这种提升。

## Abstract
The classification accuracy of pretrained Vision-Language Models (VLMs) relies on the quality of the text prompts. Handcrafted templates and Large Language Model (LLM)-generated descriptions not only make predictions more interpretable, but also enable reuse of the same prompts across heterogeneous VLMs. Recent works construct task-adapted text prompts with a small number of labeled images. However, existing few-shot text prompting methods do not explicitly focus on misclassified examples during prompt construction, leading to only marginal improvements even as more shots become available. To fully exploit few-shot supervision, we propose Text Prompt Boosting (TPB), an AdaBoost-inspired framework that treats each text-prompt-based classifier as a weak learner and sequentially aggregates them into a strong ensemble by explicitly targeting hard, misclassified examples. Extensive experiments show that TPB preserves task-intrinsic, model-agnostic cues in text space, enabling robust cross-model transfer. Across eleven classification benchmarks, TPB improves accuracy on the source model and preserves shot-driven gains when transferred to larger, more capable VLMs, where existing methods struggle to sustain such improvements.

### 1. 论文的核心问题与整体含义（研究动机和背景）

*   **核心问题**：现有用于视觉-语言模型（VLMs）的少样本提示学习（Few-Shot Prompt Learning）方法存在缺陷。它们通常以整体验证准确率为优化目标，导致生成的提示被“简单样本”主导，在准确率饱和后无法进一步利用额外的标注数据，呈现出**样本可扩展性差**的问题。
*   **整体含义**：本文提出的**文本提示增强（Text Prompt Boosting, TPB）**框架，旨在解决上述局限性。TPB 的核心思想是将 AdaBoost 集成学习与离散文本提示相结合，通过迭代地关注“难样本”（误分类样本）来构建一个强大的文本提示集成，从而充分挖掘少样本监督信号的潜力。此外，由于优化的是自然语言文本提示，该方法天然具备在异构 VLM 间**跨模型迁移**的能力，且比连续提示方法更为稳健。

### 2. 论文提出的方法论

*   **核心思想**：将每个由类特定提示词库（Prompt Bank）构成的分类器视为一个弱学习器，利用 AdaBoost 算法在少样本数据上迭代训练多个弱分类器，并根据加权误差迭代更新样本权重，迫使后续轮次的弱分类器专注于解决之前被误分类的样本，最终通过加权投票聚合为一个强分类器。
*   **关键技术细节与流程**：
    1.  **构建大规模提示池**：在训练前，将手工模板（来自 CLIP）、LLM 生成的描述文本（来自 DCLIP、CuPL 等）及其拼接结果合并，为每个类别构建一个丰富多样的候选提示池 \( P_k \)。
    2.  **弱学习器：贪心提示组合（Greedy Prompt Composition, GPC）**：
        *   **目标**：在每轮增强中，从提示池里为每个类选择一个提示子集，构成当前轮的弱分类器，以最小化当前样本权重下的加权分类误差。
        *   **阶段 1：单模板初始化**。从 80 个手工模板中，选择一个使当前轮加权误差最小的模板，为所有类别生成一个基础的提示集合，作为优化的起点。
        *   **阶段 2：类级贪心提示插入**。在初始提示的基础上，循环遍历所有类别。对于每个类别 \(k\)，评估将该类别提示池 \(P_k\) 中的每个候选提示 \(t\) 加入当前提示词库（允许重复添加同一提示以等效地调整其权重）后，对加权误差的减小量。选择能使**加权误差变化/重复次数** 指标最优的提示进行添加，直到对所有类别的完整遍历都无法再降低误差为止。
    3.  **集成到 TPB 框架**：
        *   **图像增强**：在每轮训练 GPC 之前，对少样本数据集进行随机裁剪、翻转等图像增强，防止模型快速过拟合少量样本。
        *   **权重更新与最终集成**：使用 GPC 生成的分类器对原始（未增强）样本进行评估，根据 AdaBoost 的多分类变体（SAMME.R）的规则更新样本权重，增加难样本权重，降低简单样本权重。重复多轮后，使用 SAMME.R 的聚合规则将所有弱分类器集成，得到最终的强分类器。

### 7. 优点

*   **创新性强**：将经典的 AdaBoost 思想巧妙应用于文本提示学习领域，将提示组合视为弱学习器，是解决少样本过拟合和可扩展性差问题的新颖视角。
*   **性能优异且逻辑清晰**：方法不仅在源模型上具有更好的可扩展性，在跨模型迁移任务上更是显著优于现有方法，且保持良好的可解释性（因为是自然语言）。

*   **分析深刻**：通过对比 PEZ 的失败案例，本文深刻洞察了文本提示迁移性的根源，对领域有重要启发。
*   **实验扎实全面**：实验覆盖了极其广泛的数据集、模型架构和规模，并由丰富的消融和定性分析支撑，结论可靠。

### 8. 不足与局限

*   **构建成本高**：TPB 的迭代训练和候选搜索过程（尽管是贪心的）在大规模数据集上可能带来不可忽视的计算开销。
*   **数据噪声敏感性**：AdaBoost 的重加权机制可能会过度强调少数噪声标签或非典型的样本，从而对最终模型产生潜在的不良影响。
*   **提示池的依赖性**：TPB的性能受限于初始构建的提示池的质量和覆盖面，对于某些极度细粒度或类别歧义大的任务，固定的提示池可能不够灵活。
*   **超参数依赖性**：性能对增强因子（\(a\)）、增强轮数（M）等超参数比较敏感，需要谨慎选择，如固定曝光预算下的分配实验所示。
