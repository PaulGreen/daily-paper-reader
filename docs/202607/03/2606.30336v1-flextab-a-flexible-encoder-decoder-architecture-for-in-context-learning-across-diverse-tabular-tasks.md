## 摘要
我们提出FlexTab，一种面向表格数据上下文学习的灵活编码器-解码器架构，它将一个任务无关的编码器与一组任务特定的解码器相结合。与现有表格上下文学习方法将特征表示与特定预测目标纠缠不同，我们的设计产生与目标无关的行嵌入，可在表原生的上下文学习框架下广泛用于多种下游任务。我们在六个不同问题上展示了这种灵活性：分类、回归、异常检测、聚类、实体匹配以及关系数据库中的实体分类。编码器和任务特定解码器均在大量真实世界无标签表格语料上进行训练。FlexTab在分类、回归、异常检测和实体匹配上取得了最先进性能，同时在关系环境下的实体分类上与专用模型保持竞争力。这些结果表明，单一共享编码器搭配任务特定解码器，可以作为多样化表格预测问题的有效通用骨干。推理代码和模型检查点将在https://github.com/SAP-samples/flextab公开提供。

## Abstract
We introduce FlexTab, a flexible encoder-decoder architecture for in-context learning on tabular data that pairs a single, task-agnostic encoder with a suite of task-specific decoders. Unlike existing tabular in-context learners, which entangle feature representations with a specific prediction target, our design produces \textit{target-agnostic} row embeddings that can be leveraged across a wide range of downstream tasks within a table-native in-context learning setup. We demonstrate this flexibility on six distinct problems: classification, regression, anomaly detection, clustering, entity matching, and entity classification in relational databases. Both the encoder and the task-specific decoders are trained on a large corpus of real-world, unlabeled tables. FlexTab achieves state-of-the-art performance on classification, regression, anomaly detection and entity matching, while remaining competitive with specialized models on entity classification in a relational setting. These results demonstrate that a single shared encoder, paired with task-specific decoders, can serve as an effective general-purpose backbone for diverse tabular prediction problems. The inference code and checkpoints will be made publicly available at https://github.com/SAP-samples/flextab.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有表格上下文学习（ICL）模型的局限**：TabPFN、TabICL、Mitra、ConTextTab 等方法虽然在分类/回归上超越了传统模型，但它们的特征表示与预测目标深度耦合（target‑aware），导致同一个模型难以原生支持多种表格任务。
- **多任务灵活性缺失**：当前方法若想处理异常检测、聚类、实体匹配等任务，就必须将问题强行转换为单表分类/回归，或者对架构进行大幅改动并重新训练，无法共享统一的特征提取器。
- **核心研究问题**：能否设计一种表格 ICL 架构，将 **目标无关的特征编码** 与 **任务特定的解码** 分离，从而用一个共享骨干网络原生支持分类、回归、异常检测、聚类、实体匹配以及多表关系推理等多样化任务？

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体架构
- **编码器‑解码器分离**：一个任务无关的编码器从表格中提取 **目标无关的行嵌入**（Row Embeddings），多个任务特定的解码器通过交叉注意力从这些嵌入中做出预测。
- **编码器**：
  - 采用 2D 注意力块（交替跨行和跨列注意力），类似于 ConTextTab 的设计。
  - 输入表格经数值/类别/时间嵌入后，形状 `(B, R, C, D)`，并附加可学习 `[ROW]` 令牌，得到 `(B, R, C+1, D)`。
  - 跨行注意力中，查询行只关注上下文行，避免泄露。
  - **多层级特征聚合**：从编码器每一层收集 `[ROW]` 输出，分别通过线性投影、求和，再经共享线性层生成最终行嵌入，而不是仅用最后一层。
- **解码器**：
  - 与编码器相同的 2D 注意力块，但跨列注意力的 KV 来自编码器的行嵌入，Q 为目标列。跨行注意力仅作用于目标列。
  - **分类/回归解码器**：共享参数，分类使用交叉熵；回归被改装为对分位数箱的分类（预测分位数概率分布）。
  - **异常检测解码器**：使用二进制目标，训练同时应对无监督、一类、半监督三种场景。
  - **聚类解码器**：不提供任何目标，输出每个行的嵌入向量，训练时使用余弦相似度与二值交叉熵，推理时用 K‑means。
  - **匹配解码器**：两张表分别编码，解码器通过交叉注意力同时关注两表的行嵌入，输出行对的匹配标签。
  - **多表关系解码器**：对根表和相关子表进行编码，拼接所有行嵌入送入解码器，利用不同表的行令牌实现关系推理。

### 2.2 训练流程
- 先用**分类/回归任务**联合预训练编码器和分类/回归解码器（最成熟的 ICL 训练范式）。
- **冻结编码器**，分别训练其它任务解码器，使用相应任务生成策略和损失函数。
- 所有训练数据来自约 **30 万张真实世界未标注表格**（内部专有语料），通过随机采样、子表划分、目标列选择等方式动态生成训练样本。

## 6. 论文的主要结论与发现

- **单编码器多解码器框架可行**：FlexTab 在分类、回归、异常检测（各种监督水平）、实体匹配上均达到 **SOTA** 性能，在关系实体分类上亦有竞争力。
- **目标无关嵌入的优势**：与目标感知嵌入相比，FlexTab 的行嵌入在语义丰富的表格（如 CARTE、TextTab）上表现显著更优，在数值为主的任务上与当前最优模型不相上下。
- **匹配任务**：专用匹配解码器远超简单相似度匹配和将匹配转为单表分类的 ICL 方法，证明了分离架构在跨表推理中的价值。
- **多表关系**：通过编码器独立编码、解码器跨表推理，能有效利用辅助表数据，且性能随辅助行数增加而提升。

## 7. 优点：方法或实验设计上的亮点

- **架构解耦**：严格分离目标无关的编码表示与任务特定解码，使得一个骨干网络即可原生支持多种表格任务，无需改变编码器。
- **多层级聚合**：从所有编码器层收集信号并线性聚合，比仅用最后一层更稳定、效果更好，且避免了训练坍塌。
- **统一训练框架**：所有任务均利用大规模真实世界表格动态生成训练数据，无需人工标注或合成先验。
- **回归的量化处理**：将回归转为对分位数箱的分类，简化训练并支持不确定性估计。
- **公平且全面的验证**：在语义和数值两大类任务上均与调优后的强基线（包括 AutoGluon 堆叠模型）对比，并辅以消融与显著度检验。

- **信息瓶颈风险**：每行压缩为单个嵌入，对宽表或需细粒度单元格推理的任务可能丢失信息（实验中也观察到在列数较多时排名略降）。
