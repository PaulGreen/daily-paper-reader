## 摘要
自动提示优化（APO）已被广泛采用，用以在不更新权重的情况下将视觉-语言模型（VLMs）适配到下游任务，并取得了有希望的结果。然而，在多模态任务中，APO的效果从根本上受到盲目反馈通道的瓶颈限制：优化器读取问题、预测和正确答案，但从未看到模型失败的输入图像，因此无法诊断视觉层面的错误。作为补救措施，我们引入了跨模态视觉反馈（CMVF）。CMVF包含（1）一个以失败为条件的视觉诊断阶段，在此阶段中，更强的优化器VLM在无法访问预测或标签的情况下检查每个失败图像，以及（2）一个错误感知聚合阶段，将这些观察结果压缩为可复用的、任务级别的视觉盲点模式，驱动提示改写。关键是，图像仅在优化期间被使用；部署的产物是一个普通的文本提示，其在推理时的成本与任何纯文本基线相同。在12个VQA数据集和4个目标VLM上的大量结果表明，CMVF始终排名第一，平均在每个目标上比最强基线提升2.4个百分点，个别基准上的提升高达6.5个百分点。此外，优化器能够自我组织成专家式的视觉检查清单，这些清单可以在无需重新优化的情况下跨模型迁移。

## Abstract
Automatic prompt optimization (APO) has been widely adopted to adapt vision-language models (VLMs) to downstream tasks without weight updates, yielding promising results. However, on multimodal tasks, the effectiveness of APO is fundamentally bottlenecked by a blind feedback channel: the optimizer reads the question, the prediction, and the gold answer, but never the input image on which the model failed, and therefore cannot diagnose visually grounded errors. As a remedy, we introduce Cross-Modal Visual Feedback (CMVF). CMVF incorporates (1) a failure-conditioned visual diagnosis stage, in which a stronger optimizer VLM inspects each failed image without access to predictions or labels, and (2) an error-aware aggregation stage that compresses these observations into reusable, task-level visual blind-spot patterns that drive the prompt rewrite. Crucially, the image is consumed only during optimization; the deployed artifact is an ordinary text prompt that runs at the same inference cost as any text-only baseline. Extensive results across 12 VQA datasets and 4 target VLMs demonstrate that CMVF consistently ranks first, improving over the strongest baseline on every target by 2.4 points on average, with gains of up to 6.5 points on individual benchmarks. Moreover, the optimizer self-organizes into expert-style visual checklists that transfer across models without re-optimization.

### 1. 论文核心问题与研究动机
- **核心痛点**：当前的自动提示优化（APO）在视觉语言模型（VLM）上存在“视觉盲区”。优化器在根据模型错误重写提示时，只能看到问题、模型预测和正确答案，而看不到模型出错的图像。这就像老师批改试卷时不看图表，只能知道错了，但不知道错在哪里。
- **研究意义**：多模态任务中的错误往往源于视觉细节的误判（如混淆解剖切片层次、忽略坐标轴标签等），纯文本反馈无法诊断此类错误。论文旨在打通从视觉错误到文本提示优化的闭环，突破APO的性能瓶颈。

### 2. 方法论
论文提出了**跨模态视觉反馈（CMVF）**框架，其核心思想是在优化过程中引入失败图像的视觉诊断，并在推理时保持零额外成本。

- **两阶段视觉诊断通道**：
    - **阶段1：问题感知的视觉描述**。针对每个错误样本，优化VLM仅根据图像和问题生成视觉描述，**不提供预测和真实答案**，从而杜绝事后理性化（post-hoc rationalization），强制记录纯粹的感知层证据。
    - **阶段2：错误感知聚合**。将单个错误样本的视觉描述与文本错误三元组（问题、预测、真实答案）配对，交由优化VLMs摘要出重复出现的**视觉盲点模式**。这一步将大量个例描述压缩为少而精的诊断指令（如“检查小文本”、“验证解剖切片层次”）。

- **融合、提示更新与推理**：
    - 将准确率统计、正确/错误样本数量与压缩后的视觉盲点模式拼接，形成统一反馈 \(g^{\text{CM}}_t\)。
    - 提示按照 \(p_{t+1} = \text{Update}(p_t, g^{\text{CM}}_t)\) 方式更新，默认更新函数为TextGrad风格的文本梯度重写。
    - **推理阶段**，部署的产物是完全普通的文本提示，目标VLM仅接收图像、问题和优化后提示，**没有任何额外的VLM调用或图像分析**，推理成本与纯文本基线完全一致。

- **建模直觉**：通过一个简单的错误成因分解模型 \(E[\Delta L_{\text{CM}} - \Delta L_{\text{text}}] \gtrsim \alpha_V I_V - \delta_T\) 说明，当视觉成分导致的错误比例 \(\alpha_V\) 越大，以及聚合步骤越能提升视觉信息的有效程度 \(I_V\) 时，CMVF相比纯文本APO的优势就越明显。

- **泛化性更好与成本可接受**：CMVF表现出最小的验证-测试泛化差距，且能在纯文本基线平台期后继续改进。训练时间仅增加约25%，推理成本为零增加。

### 7. 优点
- **首次打通多模态APO的视觉反馈闭环**：提出并验证了“盲反馈”这一根本瓶颈，解决了APO无法感知图像的错误诊断问题。
- **模块化、即插即用的设计**：CMVF可与TextGrad或REVOLVE等不同更新器结合，方法独立于具体重写器。
- **零推理成本增加**：优化阶段引入视觉，但最终部署产物为标准文本提示，对推理服务完全透明，实用性极强。
- **广泛而严谨的验证**：涵盖12个数据集、4个VLM、6种基线、多项精细消融和统计检验，结论可靠。
- **可解释性涌现**：优化过程中自发产生人类可读的、任务特定的视觉检查策略，且策略可跨模型迁移。

### 8. 不足与局限
- **训练时开销**：相较纯文本APO有约25%的训练时间增加，对追求极致训练效率的场景仍有成本。
- **依赖强优化模型**：效果受限于内置的优化VLM（Qwen3.5-9B）的视觉诊断能力，对于更复杂或专业性极强的图像，其视觉描述与诊断质量可能成为新上限。
- **错误数量截断**：聚合阶段单步最多接收30个错误样本并进行字段截断，当任务错误极为多样时，可能丢失部分稀疏但有价值的失败模式。
- **数据集偏差**：实验主要集中在VQA风格的多模态任务上，对图像描述、多轮对话等多模态任务的应用尚未验证。
- **分析粒度**：虽展现了可解释的检查清单生成，但未对清单中具体条目的有效性做逐项归因实验，也未讨论是否可能产生误导性视觉规则。
